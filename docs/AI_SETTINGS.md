# 全站AI服务设置

0.33继续共用这一套连接：整站翻译、产品/文章翻译、正文SEO和小批量内容均不另设密钥。AI服务页增加翻译术语、批量内容、用量与价格，均为普通业务入口；价格由用户自填，用量只采用接口真实返回值，缺失不会显示为0。外部AI客户端可选择[MCP OAuth](MCP_OAUTH.md)或原独立Bearer/Skill，不读取本站AI密钥；连接后仍需负责人确认采用。

0.32增加可选“看图检查使用的模型”：与文字模型共用连接和密钥，留空使用默认模型。普通连接测试仍是文字测试，不能证明支持图片。只有在[视觉检查](AI_VISUAL_REVIEW.md)明确勾选图片并同意发送时才调用图片接口；[产品长详情](PRODUCT_LONG_DETAIL.md)与[翻译](AI_TRANSLATION.md)复用文字模型。保存配置不会生成内容。

管理员在 **站点设置 → AI服务** 统一维护服务地址、模型、API密钥和启用开关。现有整站建站、PDF资料整理、页面局部修改、SEO建议共用原 `/api/ai/provider` 配置。0.18.0已接文章和产品文案，复用同一设置；服务连接和写作资料在设置页分开维护。操作见[AI内容写作](AI_CONTENT_WRITING.md)。

业务中的 **AI服务设置** 打开同一表单的“站点设置 · AI服务”抽屉，保留下面页面和窗口的挂载。关闭后继续核对资料、填写指令或查看方案，无需跳到建站页寻找配置。保存后各业务重新读取本机配置状态，不自动整理、生成、采用或发布。

配置和连接测试使用顺序：

1. 填写自己的兼容服务地址、模型和密钥。
2. 点击 **保存AI配置**。保存不测试连接，不消耗模型请求。
3. 需要验证时，明确点击 **测试已保存连接**；此操作会发送一次请求并可能消耗自己服务商的额度。
4. 启用 **AI功能** 并保存，再在具体业务中主动生成。

密钥保存后不回显，同一服务来源下留空保留；更换来源或移除密钥沿用原服务端校验。未保存的配置仅在当前表单内存中，离开可明确放弃，不写入浏览器恢复、站点内容或导出文件。加载中或读取失败不能保存空配置；版本冲突会保留输入，读取最新配置版本后需要人工核对再保存。

实例的固定密钥和加密数据应一同随完整备份保留，升级时可继续使用已保存的服务配置。写作时可选择自己的 PDF 或表格摘录、产品参数作为依据，建站预填也需要确认所选资料。连接测试通过后，可用实际资料分别检查文案、SEO 或图片输入能力。
