# 从资料到网站的建站流程

0.17.0。管理后台的“建站流程”把现有功能串成五步。可以按顺序完成，也可以继续完善已有网站；当前所在步骤只是操作位置，不代表其他步骤已经通过审核。原页面、产品与拖拽编辑器仍使用同一份真实草稿。

## 1. 准备资料

有公司PDF或产品Excel时，从流程进入资料导入，先查看提取结果并核对。PDF可人工摘录，也可主动使用自己配置的AI整理；Excel可核对列、修改单元格、选择导入行，明确确认后才保存产品草稿。没有文件时直接填写企业介绍、主要产品、目标客户与市场即可。

上传和本地提取不调用AI。接口、扫描件、文件大小及格式范围见[资料导入指南](AI_SOURCE_IMPORT.md)。上传来源存在不代表已完成审核或产品导入；过期来源也不表示之前确认保存的产品已经丢失。

## 2. 生成网站

配置自己的模型服务、模型名称和密钥后，主动生成方案。系统没有共享账号或内置额度；“已启用”只表示保存了启用设置，不等于连接、模型能力或余额已经验证。连接测试也会发一次请求。

核对方案和真实业务事实，比较设计方向，再生成私有页面预览。满意后明确保存为草稿，接着进入原拖拽编辑器。已有网站默认保留原内容、另生成草稿目录；没有AI时仍可使用现成案例或手工创建页面。具体保护和产品范围见[AI建站指南](AI_SITE_BUILDER.md)。

尚未过期的本人方案可从流程显式继续读取。继续读取不重新调用模型或采用修改；过期、删除或工作区已变化时应按界面提示重新核对，系统不会自动补发收费请求。

## 3. 自由编辑

选择已有页面，在原编辑器改文字、换图片、拖拽布局并调整手机端效果。局部AI修改是可选帮助，仍需明确生成、预览和采用；保留和锁定范围、撤销规则见[局部修改指南](AI_PAGE_EDIT.md)。

从编辑器返回流程或进入搜索检查时，会先保存当前画布；保存失败会留在编辑器，不能把“点击下一步”当成保存成功。普通用户仍能继续手工编辑AI生成的普通组件。

## 4. 搜索检查

先运行本地检查，核对标题、介绍、图片说明、链接与收录意图。没有Google或关键词接口也能完成本地检查和手动修改；这些接口是按需使用的持续优化功能，不是首次建站的必备条件。

想参考搜索数据时，再配置自己的Google只读授权或关键词接口，也可以导入已有CSV。搜索标题和介绍先预览、确认后保存草稿，按原规则可安全撤销；收费查询必须先确认，不自动请求。数据口径和边界见[搜索优化指南](SEO_WORKSPACE.md)。

## 5. 检查并发布

先看桌面和手机的草稿效果，再进入原发布检查，选择本次范围、核对依赖和变更，最后明确确认发布。进入该步骤不会自动勾选全部内容或发布网站。

“已有公开版本”只说明当前实例有发布记录，不代表最新草稿都已发布，也不能证明域名、证书、Google收录或搜索效果已验证。公开版本回退和草稿恢复沿用现有工具。

## 中断后继续与隐私

同一标签页仅按当前账号保存步骤和页面/生成记录ID，不在这份流程记录中保存原文件、表单内容、模型产物或密钥。原业务模块的未保存输入沿用各自恢复提示；恢复输入不会自动导入、调用AI、采用建议或发布。

浏览器禁止存储、清理会话或新开其他设备后，流程位置可能回到起点，数据库里已经确认保存的内容仍保留。页面或生成记录已删除、方案已过期时，入口会重新核对真实状态，不能把旧ID当作完成凭证。

实现入口：`src/lib/site-journey.ts`只保存安全位置与汇总真实内容，不设置虚构完成率或SEO分数。接口仍由用户自行配置；本轮验证范围以专项验收和执行板为准。

## 全站AI服务的设置入口

在 **站点设置 → AI服务** 统一设置服务地址、模型、密钥和启用开关。建站、PDF整理、局部修改、SEO建议共用这份配置。业务中的 **AI服务设置** 快捷打开同一设置表单，不离开当前页面，关闭后仍保留正在核对的资料或方案。保存配置不会自动测试、生成、导入、采用或发布。

文章撰写和产品介绍生成属于后续功能，接入时复用全站AI服务。
