# 正文排版、文中图片与封面

在内容管理中选择案例、新闻、团队或自定义栏目后，即可进入写作页。主区域编排正文，右侧维护封面、栏目信息和网站状态。

## 新建与继续编辑

1. 进入“内容管理”，选择栏目，再新建案例、新闻或成员；已有内容直接点击标题或“编辑”。
2. 在主区域选择封面、填写标题、摘要和正文。栏目已有的国家、职位、日期等专用资料仍可填写。
3. 点击“保存草稿”写入数据库，保存后留在当前文章，可以接着排版和补图。
4. 点击“返回…列表”回到所属栏目；未保存修改需选择保存、继续编辑或明确放弃。上传尚未完成时先等待，避免图片没处理完就提交或离开。

打开旧文章会显示原来的文字，不会因此自动保存、改写字段类型或标成有修改。已有自定义栏目的正文按原填写项目识别；没有正文项的栏目仍保留其专用资料，管理员可在栏目设置中添加。栏目、分类及产品参数入口见[内容管理说明](CONTENT_MANAGEMENT.md)。

## 正文怎么排版

正文工具栏提供正文段落、二级/三级标题、粗体、斜体、下划线、项目列表、编号列表、引用，以及左/中/右对齐；也可添加或解除文字链接、撤销和重做。选中文字后使用相应工具；文章名称由页面主标题负责，不必把正文第一段再做成一级标题。

正文保存为结构化文档，粘贴的文字与支持的排版经过编辑器规则处理；任意脚本、iframe、事件属性和不受支持的HTML不会作为文章代码保存。外部图片请通过“插入图片”上传或选择本实例素材，系统不会自动抓取远程图片。当前可用功能以工具栏为准。

## 封面与文中插图

封面是文章列表中的主图，正文图片位于文字之间，两者独立维护。封面可直接上传，也可从素材库看缩略图选择；详情页封面如何展示仍由该栏目详情模板决定。搜索或分享时需要单独的图片，可以在搜索与分享设置中填写。

插入正文图片时：

1. 把光标放到需要插图的位置，点击“插入图片”。
2. 上传图片或从素材库选择；填写“图片描述”，需要时补“图片下方说明”。
3. 选择25%、50%、75%或100%显示宽度，以及左、中、右对齐，再点击“插入正文”。
4. 点击正文中的图片，可以调整宽度、编辑描述与说明，或删除这张文中图片。

替代文字用于无障碍阅读和图片含义，图注显示在图片下方。上传和素材库选择期间会保留插入位置，不会因为选择弹窗夺走焦点而插到文章开头或别的段落。取消选择保留原正文。

图片沿用JPG、PNG、WebP和每张最多8 MB的素材规则，上传归入“内容图片”；同一素材可以复用。删除文中图片或更换封面只修改当前文章，不物理删除素材。仍在正文或其他草稿中使用的图片不能从素材库移除，历史版本中的文件也继续保留。

## 保存、预览和更新网站

“有未保存修改”表示当前输入尚未写入数据库。网站状态区区分：

| 状态 | 含义 |
| --- | --- |
| 草稿 | 当前内容尚未发布到网站 |
| 有修改待发布 | 网站上已有这条内容，但保存的草稿还有待更新部分 |
| 已发布 | 保存的内容与当前公开版本一致 |

“保存草稿”保留工作，不直接更新公开网站。点击“预览”时，如果编辑者有未保存输入或正在新建，会先保存草稿，再打开该文章的实际详情预览；只读查看不会保存。栏目尚未设置详情页时，需先完成栏目详情页设置。

管理员可在右侧点击“检查并发布内容”或“检查并更新网站”。该入口仍使用原发布检查与确认：核对文章、栏目、详情模板、图片等依赖和影响，按提示调整范围并重新检查，最后确认更新。编辑者填写与预览，网站发布由管理员确认。一次保存、预览或打开编辑页都不会绕过发布检查。

## 维护与数据兼容

正文排版作为现有多行文本字段的可选结构化副本保存。字段类型、字段 ID、详情模板和记录 ID 保持不变。旧纯文本记录打开时只生成显示用文档，编辑并保存后才写入结构化副本。

`customFields[fieldId]`保留严格等于`richTextPlainText(doc)`的字符串，供搜索、SEO、查询和普通文本用途使用。段落块之间是双换行，单次换行为单换行；图片只把下方说明计入正文文字，不把图片地址和替代文字混进去。只有图片、没有图注的正文，文字投影是空串，但图片仍算有效内容，不能被表单空值清理删掉。

同一文章的排版副本与文字投影必须同时一致。已有排版时，旧客户端更新整条记录却省略`richTextFields`会返回422；明确提交`richTextFields:{}`才表示清除排版，并需提交想保留的普通文字。这样可防止不了解新字段的客户端静默丢失格式。接口或导入脚本应按此约定更新，不能只把原正文字符串换成HTML。

原`Text`组件绑定该多行文本字段时，会在详情、共享区块和循环卡片中安全显示排版，不需要把旧模板重新搭一遍。正文图片参加原素材引用、删除保护、所选发布、历史回退/恢复、导出和整站分发；分发同时映射字段ID、图片URL与站内链接。普通字段映射导入保持原文字格式，完整排版通过整站分发保留。技术结构与升级约定见[EDITOR_DATA.md](EDITOR_DATA.md)。

升级前保留匹配的程序、配置、数据库和媒体。完整备份与回退方法见[部署指南](../DEPLOYMENT.md#升级和回退)。

超出60000字符或2000节点的安全正文可在会话过期后恢复供修改，保存和发布仍按原限制拒绝。本地恢复另有20000节点、240000字符、12层和3MiB缓存硬上限；恢复会完整检查全部节点，后置危险链接、HTML和远程图片不会绕过检查。

升级Tiptap、Ant Design或工作区协调器后，重点复核：文中图片插入位置、排版组合与链接、图片描述/图注/尺寸、图片-only空串镜像、封面和正文独立、连续保存/预览、不丢未保存输入、权限、旧模板安全显示、素材引用与分发、明确发布，以及三端实际可见区域。
