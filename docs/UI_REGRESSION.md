# UI自动回归

这套检查使用项目锁定的`@playwright/test`测试依赖，创建自己的临时站点、账号和数据。无需个人浏览器Cookie、父work目录或固定电脑路径，也不会复用正在运行的正式站。

## 运行

在项目目录安装依赖并构建，首次使用时主动安装浏览器：

```sh
npm ci
npm run test:ui:install
npm run build
npm run test:ui
```

以后修改界面，重新构建后运行`npm run test:ui`。测试使用当前已有的生产构建，不在运行中重写`.next`；构建与UI测试不要同时执行。`test:ui:install`只安装Playwright对应的Chromium，测试本身不会自动下载浏览器或安装系统软件。Linux CI的系统依赖按[官方浏览器安装说明](https://playwright.dev/docs/browsers)配置。

可以显式复用电脑已有Chrome，PowerShell示例：

```powershell
$env:UI_TEST_CHANNEL = 'chrome'
npm run test:ui
Remove-Item Env:\UI_TEST_CHANNEL
```

留空使用Playwright Chromium；另支持显式`msedge`。这些是桌面浏览器的响应式视口检查，不能当作真实iPhone/Safari或所有系统浏览器验收。

## 查看结果

```sh
npm run test:ui:report
```

- 每次运行保留独立的`output/ui-regression/<时间-随机ID>/`，包含HTML报告、`results.json`、失败截图、浏览器异常摘要和本轮`summary.json`。
- `output/ui-regression/latest.json`指向最近一次，只有真实执行成功且临时目录和端口清理成功才显示`passed`。`fullSuite`说明是否运行整套，统计包含通过/失败/跳过/波动及耗时。
- `npm run test:ui:list`仅发现用例，也会检验临时实例初始化和合成数据准备。结果为`listed`，不是执行成功；其Playwright统计可能显示所有用例skipped，不得据此声称跑过回归。
- 可以定点调试：`node scripts/test-ui.cjs --grep "主题未保存"`。PowerShell中的`npm.ps1`可能吞掉后续CLI选项，使用上述直接node命令更明确。定点结果会标记`fullSuite:false`。
- 失败返回非零退出码，不自动重试；所有尝试保留在各自run目录，不用一次成功覆盖旧失败证据。

`npm run test:ui:policy`快速检查包装器的配置覆盖拒绝、零执行/跳过不能算通过、list口径与清理状态约束，不启动站点或浏览器。CLI仅允许`--list`、`--grep`、`--headed`，其他参数在启动实例前拒绝；参数校验失败不会覆盖最近一次实际执行的报告。运行中即使Playwright退出0，零执行或跳过也会先记录`failed`再返回非零。

## 检查内容

当前配置共57条业务UI用例，包含原有后台回归和历次AI功能闭环；部分包含375/390两种手机宽度，另有768平板和1600桌面。用例数量不代表本轮已经全部通过，实际状态以对应run的`summary.json`为准：

| 范围 | 行为 |
| --- | --- |
| AI设计 | 临时本机模型、未配置入口、动态产品卡片、三端真实沙箱及检查、候选手机继续调整、确认、原生卡片编辑、撤销；结束恢复测试资料与配置 |
| 侧栏 | 真实点击出现Ant Wave时仍保持名称/域名两行；长文本、空值、hover、键盘和移动抽屉 |
| 产品 | 语言与标签组合完整清除；单语言GET布局夹具保证分类至少140px；长名称/型号/字段展开可读且0/No（false）不丢；分页切宽不重置 |
| 真实只读账号 | 搜索/分类/页面与版本详情及纯查看分页可用，新增/勾选/编辑/上传仍禁用；带正确Origin的写入被角色权限403拒绝且数据不变 |
| 未保存保护 | 主题继续编辑/保留恢复/放弃；资料和素材真实保存后刷新；明确503失败保持输入，错误条不遮挡弹窗 |
| SEO | 本地实际诊断；明确标记的合成GSC/关键词GET报告，检查手机详情、0与缺失、来源/周期、逐月资料和跨宽度分页 |
| 发布版本 | 临时站真实生成的快照，手机完整路径/型号/扩展字段与内容详情，桌面完整列、分页及切宽状态 |

断言测量实际排版和点击命中，不强制点击、不插入DOM样式，不用整张像素截图作为跨平台唯一判断。HTML报告与失败截图用于定位；它们不能取代人工检查设计质量。

工具本身另有6项无需启动实例的边界检查：

```sh
node --test tests/ui/runner-policy.test.cjs
```

检查配置覆盖参数被拒绝，零执行、缺失统计、跳过、波动、构建被替换和清理失败不能显示passed。即使运行器异常退出0，也先写入本轮failed统计，避免旧的latest成功记录误导维护者。

## 隔离与数据边界

`scripts/test-ui.cjs`在系统临时目录`mkdtemp`建立实例，随机选择本机端口，明确拒绝3200。子进程只继承系统运行必需环境白名单；认证密钥、密码随机生成，账号与认证表均为本轮合成资料。管理员和只读成员通过真实认证API登录，角色不是GET响应伪装。

Next在临时runtime目录启动，只链接现有`.next`、`node_modules`和`public`，复制不含秘密的配置；runtime没有源码根的`.env.local`。setup显式指定临时配置文件，数据和备份均指向该目录。只在此随机实例准备20个产品、19页、10条内容及一个合成发布版本；这不是正式网站发布。

浏览器默认阻断测试来源之外的请求及未声明写入；合成Next进程预加载网络保护，仅额外放行包装器亲自创建的随机本机确定模型，拒绝外网和正式3200。模型使用合成密钥，仅识别本用例标记，不向外请求；用例临时配置并在结束后恢复，包装器关闭模型端口。通知、IndexNow及真实AI/Google接口未配置，不使用已有客户资料或密钥。成功/失败和只读报告夹具在源码明确声明，不能把合成模型/GSC/关键词视为真实设计或搜索效果数据。

切换候选或Puck编辑目标会销毁旧iframe。仅对失败事件当时frame已销毁、GET、本轮明确图片路径、resourceType=image、精确net::ERR_ABORTED的取消单独记入`expectedDetachedImageAborts`；无法确定来源时仍判失败。活跃frame取消仅在已知Puck about:srcdoc+同源/admin#editor上下文、精确图片URL，并有失败之后同一编辑上下文的requestfinished与完整2xx响应时，单独记录recoveredEditorImages及失败/恢复顺序证据；其他预览的同图成功不能替代。用例通过`closeOwnedPage`显式关闭自己页面时，同一严格图片取消条件单列`expectedClosedPageImageAborts`，不豁免业务中途失败。未恢复取消、其他网络错误、页面异常及外发继续严格失败。动态产品图片另需在真实沙箱正常滚动并验证naturalWidth>0，不能用取消例外代替加载成功。

每个用例使用独立浏览器上下文；为避免修改同一临时站产生交叉污染，固定1 worker、0 retry。结束后关闭测试子进程/浏览器、核对测试端口关闭，只删除本次生成且路径复核通过的临时父目录；认证状态和随机密码不写入报告。`output/`已由Git、Docker与源码打包器排除。

锁定版本的 Better Auth 以最后一次成功请求后的完整静默期重置会话读取计数。跨用例维持正式认证行为。

为保留正式认证行为，`fixtures.ts`把观察到的会话读取时间戳写入隔离临时目录的`ui-session-reads.json`，跨worker重启累计。达到40次后，在下一用例开始前静默61001毫秒，再开始业务操作；正常静默期结束后可清空测试侧计数。等待使用fixture独立的90秒预算，业务用例和断言超时不因此放大。`browser-audit.sessionReadPacing`记录每条用例观察到的请求数和实际让步时间。它不修改正式认证配置或限流状态，不拦截、隐藏429，也不重发请求或自动重试；发生未预期429仍然失败。

默认关闭trace，失败自动保存截图与报告。仅本机排查需要时可显式设置`UI_TEST_TRACE=1`；此时整份报告及原始trace写到`output/ui-regression-private/<run>/`，可能包含临时Cookie、请求和响应。该目录不是脱敏产物，不要公开、打包或自动上传CI。认证与seed在独立的包装器API上下文完成，不录制登录密码。

失败时服务器末段日志仅保存到该run的私有目录，启动错误不拼接原日志。新整站用例的独立API控制请求只输出固定传输错误类别，并设置`Connection: close`避免浏览器操作间隔中的闲置连接复用；浏览器业务请求、超时和重试数不变。共享报告前先核对异常文本是否包含临时凭据。

## 接入CI和维护

公开仓库的 [CI](../.github/workflows/ci.yml) 运行类型检查、测试、构建、HTTP 冒烟及浏览器测试规则检查。完整浏览器用例可以本地运行或接入隔离的 CI：

```sh
npm ci
npx playwright install --with-deps chromium
npm run build
node --test tests/ui/runner-policy.test.cjs
npm run test:ui
```

分享默认报告前检查异常文本是否含认证信息，私有诊断与trace不自动上传；失败必须阻止后续发布。测试依赖升级时，同时检查[运行配置](https://playwright.dev/docs/test-configuration)、[认证状态保护](https://playwright.dev/docs/auth)与锁定浏览器版本；不要改成复用正式服务器或降低断言来让检查变绿。

入口：`tests/ui/playwright.config.ts`控制运行器，`fixtures.ts`控制每个用例的请求与异常边界，`regression.spec.ts`保存行为用例，`seo-fixtures.ts`只提供明确的报告GET夹具，`deny-external.cjs`只加载到临时Next进程。`ai-design.spec.ts`验证原生动态卡片闭环，`ai-site-design.spec.ts`验证页眉页脚、跨页导航、独立页显隐、三端预览、继续调整、原生头尾往返和撤销。每次改动后，报告中记录实际构建、浏览器、运行范围与未验收项，不将历史结果当成本轮重跑。

0.22新增`external-ai.spec.ts`：真实创建/撤销临时机器凭据、SDK提交及续调、无站内模型时的精确审核深链、人工采用/原生拖拽/撤销；运行目录额外链接固定交付docs供Skill下载，仍不链接正式配置或数据。凭据只放用例内存和独立API上下文，SDK与网络异常仅保留固定错误类别。

整站用例在未缩放的完整预览验证鼠标导航、锚点和手机菜单，在嵌入前后对比验证键盘导航。缩放 iframe 中的鼠标操作需要单独走实际交互。

## 0.23 外部内容与SEO

新增 `external-content.spec.ts` 两组实际浏览器用例：外部MCP产品部分字段采用/继续原生编辑/撤销、新富文本文章手机审核/创建/继续编辑/完整撤销，以及外部SEO深链/真实页面前后/确认和撤销。所有候选通过真实官方SDK和当前服务生成，无站内模型；控制通道和浏览器写入口独立白名单，未放宽失败请求与外发检查。

原外部连接用例同时验证新权限默认不选、真实勾选文案和SEO、指定产品与空内容范围，密钥一次显示/不进入恢复存储、角色/吊销和原设计拖拽往返继续覆盖。内容审核以原文和候选富文本排版比较，未把它标成完整详情页；SEO有实际前后iframe。

## 0.24 设计范围挑选

新增ai-site-design-selection.spec.ts：真实外部MCP准备多页、头尾与主题方案，手机选择范围、刷新恢复未提交选择/追问、准备新范围的真实预览、只保存页眉、原Puck往返及安全撤销。挑选前后均读取实际服务，未用GET替身或整站状态override；确认前不得出现草稿写入。

外部连接权限例对多选采用真实键盘输入精确完整标签、等待唯一且active过滤结果后Enter，再核对实际tag和服务器scope。一次pointer失选未稳定复现；成功事件诊断的pointer确实命中option且产生tag，不能据此声称已修表单bug或此步骤已通过pointer覆盖。其余侧栏、按钮、画布等已有实际pointer/键盘覆盖保持。

## 0.28设计约定回归

新增保存/刷新、409保输入、离开与返回保护、375/390、显式确认记住文字及只读零请求。一次真实冲突通过 `ui.expectHttpError('PATCH','/api/ai/design-guidance',409)` 预先声明；只有浏览器实际收到一次同方法/路径/状态响应，才允许对应的精确Chrome资源console，并单列审计。不模拟该响应、不忽略重复或其它异常，原503及网络/页面/越权检查保持。发布历史测试明确选择当前公开版本，不把最新历史误当长表样本。

## 0.32 视觉检查、产品图文长详情与翻译

本批新增4条UI用例，合计覆盖以下流程：

| 文件 / 数量 | 实际覆盖 |
| --- | --- |
| `visual-review.spec.ts` / 1条 | 本人候选真实三端JPEG、仅发送勾选设备、明确外发同意、真实节点定位、手机“修改前”切回时的慢装载、建议带入追问、继续生成原生候选、真实预览、确认应用及撤销；无截图浏览器时准确降级，手动移除截图及评审 |
| `product-detail.spec.ts` / 2条 | 自配AI生成长详情、保留既有图片与链接、前后对比、采用到原编辑区、原生续编保存、实际页面和撤销；原先没有长详情的产品在撤销后清空编辑区，再次保存不能把已撤销的缺省字段恢复 |
| `ai-translation.spec.ts` / 1条 | 保护型号、数字、单位和图片，实际页面前后预览、手机审核、明确确认保存、读取历史后撤销和原生续编；独立空身份验证私有预览确实拒绝访问且响应不泄漏原文、译文及记录身份 |

视觉功能在生产需要服务器安装可用浏览器，并由用户自行配置支持图片输入的视觉模型；仅保存文字模型或通过文本连通测试，不代表视觉能力可用。完整部署步骤见[AI视觉检查](AI_VISUAL_REVIEW.md)。回归使用隔离实例、本机确定模型和Chrome：截图是真实浏览器JPEG，模型回答是合成夹具，不代表真实供应商模型、审美质量、完整页面或实际翻译质量已验收。服务端截图浏览器与运行Playwright用例的浏览器是两项运行条件，包装器为本轮临时实例显式设置截图channel，不改变正式实例配置。

视觉用例在设备、修改前后和候选切换前，先通过普通滚动把外层iframe带入可见区域，再滚动真实沙箱图片并验证`complete && naturalWidth > 0`。标题出现不能代替图片完整加载，切换造成的取消不能通过放宽网络审计掩盖。定位用延迟候选响应验证真实就绪信号，不靠更长固定等待猜测成功。

新增用例组合覆盖真实业务接口、精确写入白名单、发布指针不变及清理检查；没有用GET替身替代生成、采用或撤销。检查完整浏览器回归时，请以该次运行的摘要、浏览器审计以及临时资源清理情况为准。
