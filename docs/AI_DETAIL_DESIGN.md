# AI详情模板设计

应用0.25.0。用于产品、案例、新闻、团队等详情页的可拖拽布局。站内入口为**模板与区块 → 我的页面模板 → AI调整布局**，也可从该详情模板的原生编辑器打开。仅管理员可用。

案例页面与模板可以使用当前案例的标题、简介、封面、项目资料和完整正文。预览时至少切换一条有图案例和一条不同内容的案例，确认模板读取的是当前记录。产品页面则应在手机上依次核对名称、型号与询盘入口，以及图集、说明和规格的阅读顺序。

本功能复用**站点设置 → AI服务**中用户自己配置的模型。不会附送、代填或自动购买模型服务。外部AI通过MCP或Skill提交原生设计提案时，不调用站内模型；完整外部连接方式见[外部AI说明](EXTERNAL_AI.md)。

## 如何使用

1. 先有产品或内容详情模板，以及至少一条模型兼容的真实产品或内容记录和有效默认详情页。普通页面模板不属于此入口；默认详情页仍负责网址和兜底。
2. 选择要调整的模板，用自然语言描述目标，例如：“产品图片在左，标题、介绍和参数在右，下面展示相关产品；手机变成单栏，先图片再文字。保留真实资料和当前字段绑定。”
3. 选择真实样本。自动选择只会选择**当前实际命中此模板**的记录；不假定第一条产品就是这个模板的样本。
4. 点击生成，先读AI理解的目标、设计决定、保留内容、假设和变化说明，再对比修改前后的真实页面，检查电脑、平板和手机。
5. 继续说具体调整要求，例如“保留当前结构，把手机标题缩小，相关产品卡片更紧凑”。每轮生成一次候选，不会直接保存为网站布局。
6. 满意后单独确认采用。结果进入模板草稿，可立即回原生Puck编辑器继续拖拽、改样式、绑定字段和保存。公开网站通过原有发布管理更新。

没有兼容记录、默认详情页或可解析路径时，服务会在调用模型之前拒绝生成，说明缺少的条件；不会付费生成一个没有真实样本的假预览。

## 实际命中与布局预览

详情页的选用规则继续使用现有模型、指定记录、分类、语言和优先级配置，AI设计不会启用、禁用或修改它们。

- **实际命中**：用现有`chooseDetailTemplate`选择规则核实，样本实际渲染的就是目标模板。修改前和修改后保持同一条冻结记录。
- **仅布局预览**：只有用户明确选定兼容样本时，才允许用该样本强制查看目标模板布局。界面和返回数据会显示`matched=false`，说明当前网站规则选用了其他模板或默认详情页。
- 强制布局预览可以确认采用排版，但采用仍只更新模板`data`，不会把“当前没有使用的模板”悄悄变为线上生效规则。
- 模板规则同优先级冲突、样本模型不兼容或路径解析错误会明确拒绝；不会借默认详情页或其他记录冒充目标效果。

同一候选的前后预览只开放冻结样本这一页，不允许在URL后追加路径读取候选中的其他页面。链接、动态字段和相关列表仍由原生渲染器解析；这不是发布站点的副本浏览入口。

## 可以调整什么

生成的是既有原生Puck组件树，不是图片、iframe页面或整块HTML，后续仍能自由编辑。

| 范围 | 支持内容与边界 |
| --- | --- |
| 详情结构 | 原生容器、标题、正文、图片、按钮、分隔线、间隔；移动、重排、插入和符合保留规则的删除 |
| 图文编排 | 网格/行/列、列数、间距、宽度、阅读行宽、字体、颜色、边框、圆角、图片裁切等现有原生白名单 |
| 三端样式 | 全端调整，或指定电脑/平板/手机断点；单设备只允许可隔离的样式修改，结构和文字修改需选择全部设备 |
| 指定区块 | 可从编辑器当前区块进入，范围外内容和锁定树受编译器保护 |
| 动态产品信息 | 当前产品名称、图片、介绍等内置字段；明确按产品模型限定的模板还可用对应模型的兼容扩展字段 |
| 动态案例/文章 | 当前内容的标题、封面、正文等对应模型字段；已排版正文保留原字段来源，不把样本内容硬编码进模板 |
| 相关产品列表 | 相关产品卡片使用独立原生同步区块；可调整卡片内部结构、图片和动态字段，不改其他列表共享的原卡片 |
| 现有自定义代码 | 保留原代码配置，但AI设计不编写、启用或修改脚本/CSS；候选预览不运行客户JavaScript |

“保留文字”开启时，已有静态文字、动态来源和被保护子树不能被重新编写或通过删除变相清除。关闭后可按要求调整支持的静态文案，仍不能把动态产品/文章资料转为样本硬编码。锁定内容、稳定节点ID、插槽结构、循环依赖和不兼容字段继续走现有校验。

泛用产品模板不按预览产品的模型擅自开放扩展字段。需要使用某个产品模型的参数时，先明确配置对应模板模型范围。模型字段定义、业务记录、详情网址、SEO资料、规则、模板元数据和全站头尾都不由这项设计操作改写；全站设计、写作和SEO优化继续使用各自入口。

## 真实预览、继续调整和撤销

每份候选保存最初完整网站快照与累计设计后的快照，前后页面均来自本人冻结记录。之后产品介绍或其他页面变化不会污染旧预览；权限、有效期或候选失效也不会回退到实时草稿。

初次生成后最多继续调整6次。续调必须保持同一模板、同一样本及已承诺的保留文字条件；可以更换具体设计要求、目标区块或断点。后续轮次从上一版候选继续，最初before不变。删除父候选不会破坏已生成的独立子候选。

候选未采用时有效40分钟；采用后保留7天撤销记录。每位管理员最多100条有效记录，其中未采用候选最多30条，正在生成也占配额。超限先清理不用的候选；后续生成时会清理到期记录。移除已采用记录不删除已保存网站内容，但会丢失该记录的撤销入口。

采用需要当前版本与候选基准版本完全一致。即使后来只改了另一页，也会要求重新读取并设计，避免旧候选覆盖后来工作。采用只合并目标模板的`data`和最终实际需要的新独立区块；不替换整站旧快照。相同确认重复提交不会重复追加资源或再次增加版本。

撤销只恢复该模板最初的布局并移除本次生成且可安全删除的区块，保留其他页面、产品资料、询盘、站点设置和后来修改的模板名称等元数据。以下情况拒绝直接撤销，明确说明原因并保留当前工作：

- 模板布局已有后续编辑或新锁，模板被删除或其用途、模型、规则、来源路径已变化。
- 依赖的原同步区块或内容模型已修改，旧布局需要的素材已删除或替换。
- 本次新卡片/区块已被修改，或被其他页面、模板、区块、全站头尾新引用。
- 恢复后的布局不再通过当前字段、链接、循环和依赖校验。

当前撤销以**整份目标模板布局**保护，后续在同一模板其他区块的手改也会阻止撤销；不会猜测哪些新改动可以丢弃。历史记录的`canUndo/undoReason`只表示读取时状态，真正撤销仍在事务内重新检查。

## MCP、Skill与权限

外部入口使用`site_template_overview/context/propose/status/review`，复用同一原生命令编译器、样本校验、冻结候选和后台确认界面。外部提案不会直接采用或发布；必须由创建者登录浏览器查看真实预览并确认。外部AI的会话密钥不等于后台登录会话。

`templateIds`是独立资源授权，默认空列表；旧连接不会因为拥有全部页面权限而自动获得全部模板权限。模板与样本记录分别授权：产品样本检查`recordIds.productIds`，内容样本检查`recordIds.entryIds`。缺省样本仅在已授权且实际命中的集合中选择；显式样本同样检查范围。图片与页面链接沿用外部资源投影及提交复查，不允许通过操作引用范围外素材或页面。

站内和外部路径都重新查询管理员账号与停用状态；异步模型结束、外部提交及真正采用/撤销时再次检查权限。生成期间降权、停用或草稿变化会丢弃候选，不覆盖用户工作。外部同一连接的相同请求标识和相同内容幂等返回原候选，不同内容复用请求标识会冲突。

上下文包含有界原生节点、兼容字段定义、样式、素材元数据、受限页面链接和选中样本事实，不返回整份私有快照、其他记录库、询盘、用户密钥或私有写作配置。样本扩展事实仅开放模板范围内的文字、数字、日期和选择类型；关系ID、媒体URL和URL字段不随事实字段外发。网页文案、样本和历史总结均视为不可信资料，不能改变系统授权。

## 存储、升级与维护

详情模板候选和外部请求幂等记录存放在专用私表，避免旧代码把未知模板变更误标为已采用。变更使用既有原生组件、绑定和样式协议。

详情候选和模板修改需要随实例完整备份。版本回退使用匹配的程序和数据副本，先在隔离环境验证候选、旧布局、实际样本与撤销。[升级和回退](../DEPLOYMENT.md#升级和回退)

后续更新至少回归：真正命中的产品/案例样本、强制预览标识、无样本调用前拒绝、三端样式隔离、字段绑定/已排版正文、动态卡片克隆、模板Puck无操作往返、续调最初before、严格版本、原规则/新锁/依赖保护、幂等与精确撤销，以及外部模板和记录独立授权。

## 验证范围与限制

确定模型和自动回归能验证原生操作、数据一致性、渲染与保护规则，不代表真实模型已满足某位客户的审美或完整需求。差异化设计来自具体需求、已有组件和模型生成的结构选择，不能承诺全网唯一、客户满意度或SEO排名。

可使用[AI 视觉检查](AI_VISUAL_REVIEW.md)辅助核对支持的预览。标题和排版提示用于人工审阅。缺少企业资料时应补充图片与事实，由用户确认认证、产能、项目成果及采购承诺。
