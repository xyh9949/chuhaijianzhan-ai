# 页面模板与整站分发

更新：2026-11-07。源码仍是0.6开发批次；这不是整套项目最终交付声明。

## 资源与使用

“模板与区块”分为页面模板资源库、整站分发与演示套件、旧版页面设计示例。

- 页面模板：管理员从已有页面草稿保存/更新设计；编辑员可复制布局。普通页生成独立副本，模板更新不改已复制页面。产品/模型已有默认详情时，必须明确选择替换其草稿，不能创建第二套默认详情入口。
- 同步区块：到全站设计管理，本站引用会保持同步。资源模板复制仍引用本站表单、模型、菜单、样式和同步区块；需要跨客户迁移整套依赖时用整站包。
- 页面代码默认不复制；仅管理员可检查后选择。复制JavaScript默认关闭。专用模板预览需要登录、noindex、全部客户JS关闭，原始数据与代码不受预览影响。
- 页面模板资源库可单独勾选发布/恢复。未选资源不随页面发布；历史资源及依赖媒体继续保留，不产生公开页面路径。

## 整站分发

导出只读取**当前活动公开快照**，包含其页面、产品、模型/记录、区块/卡片、菜单/页眉页脚、主题/令牌/样式、表单定义、页面模板、重定向、公开配置、代码和媒体。未发布草稿、账号/会话、询盘/通知任务、环境凭据及发布运行指针不进入包。来源站点公开邮箱等内容属于网站内容，导入后应换成客户真实资料。

管理员填写包名、说明及授权记录，下载`website.form-studio.json`。记录素材来源、作者与获准分发范围；系统不会替用户取得再分发权。应用依赖许可证不代替摄影/品牌/文案授权。三个内置套件是原创结构与明确标注的虚构演示，没有真实业绩、认证、交期或联系人。

两种导入模式：

- **空实例新建**：只接受revision0、无发布历史/询盘/上传文件的初始工作区。用来源设计替换初始示例；保持本实例账号、密钥和时区，清除来源公开域名，导入到草稿。
- **合并草稿**：保留现有页面、品牌设置、主题基础、页眉页脚与全站代码。路径加明确前缀，源主题令牌/预设和资源另建ID；页内正文保留来源示例，页眉品牌沿用本站。来源全站代码转为导入页面代码，不装到既有页面。默认产品详情冲突时保留本站入口，将来源设计保存为可应用资源；导入产品使用本站默认详情。SKU冲突要求用户显式填写前缀，不暗改型号。

合并会继承本站基础字体/主题/头尾，不能承诺与来源截图完全一致。需要还原整站时选新实例。来源关闭的代码仍保留；合并到页面时用独立函数与关闭分支保留JS原本启用边界，CSS关闭部分放在不匹配媒体规则中。只有管理员明确检查后才允许开启来源原本启用的JS。

## 预检与数据边界

选择文件或套件→选模式/前缀→预检→看路径、依赖、授权与源码→确认。预检不写入业务数据。确认签名绑定同一文件、选项、工作区revision与命名空间，5分钟有效；确认仍重新校验。409时保留原文件和输入，读取最新工作区后再预检。导入不会自动发布。

格式是带manifest、版本、快照SHA-256、逐文件SHA-256/字节数/MIME及Base64原文件的有界JSON，**不是ZIP解压器**。路径只接受`assets/<sha256>.<扩展名>`，从不把包内路径作为文件系统目标。缺文件/哈希错/路径穿越/伪造类型/未知组件/不支持版本会拒绝原包，不尝试删除未知节点。浏览器“保留原分发包”可重新下载原输入；服务器不把原包或导入任务当作公开页面。

限制：JSON请求72 MiB，媒体原字节合计48 MiB，文件最多2000个；图片8 MiB/4000万像素、PDF10 MiB/1000页、视频40 MiB。草稿仍受4 MiB及各模型/页面上限约束；代码每段100 KiB、整站1 MiB。合并代码超限也拒绝，不能静默截断。DOM作用域展开最多200000项，复杂站点需拆分。PDF沿用隔离worker解析，视频只检查容器签名；不等同杀毒或完整视频解码。

页面、产品、记录、模型、模型字段、区块、菜单/项、分类/项、样式/令牌、表单/字段/选项、模板、节点与局部集合均按种类/作用域重命名。字段ID可以跨模型重复，不能用全局字符串替换。绑定、查询、稳定目标、局部链接、媒体、全站作用域及已声明生成DOM选择器随之更新。JPEG演示文件也保留原字节，导入为实例媒体ID；不覆盖应用静态文件。

CSS由PostCSS、selector-parser和value-parser解析；只改声明的选择器/资源引用，不把颜色或content文字误当ID。JS由Acorn解析明确的DOM调用/路径常量，不执行源代码。动态HTML、计算选择器、第三方接口及程序业务含义仍需要人工检查，无法通用推断。来源按内部ID排序/文本子串查询，重命名后顺序/匹配可能变化，会提示核对。不要把静态引用迁移等同任意程序语义迁移。

所有文件验证先于写入；文件索引和草稿在同一SQLite事务中提交。失败只删除本次新建的哈希文件，不删原文件或历史媒体。进程/机器在文件写入后硬中断可能留下无索引孤立文件，由容量诊断识别；不会产生可见的半批草稿。

## 版本与维护

公开/草稿协议12，读取历史1–11；网站运行数据不进入发布快照。本批没有破坏性表迁移，没有改依赖源码。恢复旧应用时用匹配版本的完整实例备份，不能只回退Git再继续写新版库。

Next配置保留pdf-lib外部依赖与worker运行路径；文件追踪同时覆盖`/api/media`和`/api/site-packages/*`，不能在升级时删去。升级Next/Puck/Ant/PostCSS解析库后至少重验：旧发布读取、模板捕获/复制/只恢复资源、A→B媒体/作用域迁移、坏包无残留、私有预览、手机布局、代码默认关闭。完整实例备份仍用服务器备份命令，分发包不能恢复账号或询盘。

解析库资料：[PostCSS](https://postcss.org/api/)、[selector-parser](https://github.com/postcss/postcss-selector-parser)、[value-parser](https://github.com/postcss/postcss-value-parser)、[Acorn](https://github.com/acornjs/acorn/blob/master/acorn/README.md)。本批版本以package-lock.json为准。
