# AI局部修改与布局调整

**局部设计用法见[AI设计助手](AI_DESIGN_ASSISTANT.md)，0.21全站操作见[AI整站设计](AI_SITE_DESIGN.md)**：支持自然语言、三端实测预览、继续调整、确认应用与撤销。下文保留0.15.0初版的历史使用说明；其中图片/动态卡片操作范围及不能继续调整的限制已由0.20扩展，当前范围以新指南为准。

入口：**网站页面 → 编辑页面 → AI调整**。先在画布或图层中选中区块，再点击AI调整，会优先带入该范围；也可在窗口内改成整个页面或其他区块。此功能仅管理员可用，其他成员继续按原权限手工编辑。

## 使用顺序

1. 在原编辑器中准备页面。打开AI窗口只读取状态，不自动生成或采用修改；点击生成前会等待并保存当前画布，确保AI处理的是服务器上的当前版本。
2. 选择调整范围和方式：**只调设计与布局**、**只改文字**、**设计与文字一起调整**。只调设计会保留已有文案；综合调整时也可勾选保留文字。
3. 用一句话说明要求，例如“左图右文，手机端改成一列”“把优势区块做成有层次的三栏卡片”，或“精简标题和正文，保留已有事实”。需要保留的其他区块，可在可选项中额外锁定。
4. 点击**生成调整方案**。使用自己配置的模型额度，一次操作只请求一次，不自动换服务或重试。服务未配置或未启用时，打开“AI服务设置”，在站点设置的同一表单中配置服务、模型和密钥；当前调整输入保留。
5. 查看**预览与对比**，切换电脑、平板和手机，展开变更清单并核对文字。桌面并列显示前后效果，手机可切换“修改前／AI建议”；预览不会自动采用AI修改或发布。
6. 满意后点击**确认应用到草稿**。仍可继续在原Puck编辑器自由拖拽、调整样式或改文字；公开网站要经过原发布流程才更新。

如果在生成后修改了指令或范围，旧预览会明确标记，需要重新生成后才能直接应用。历史中的方案可以独立查看与审核；应用时仍会检查当前草稿版本，不能覆盖生成后的新修改。遇到冲突时可点击**读取最新工作区**，保留指令和方案后重新核对，不自动重发模型请求。

## 保护范围

AI只接收所选范围的有限文字和布局信息及必要品牌设计约束，不发送其他页面正文、原始PDF/Excel、询盘、成员或API密钥。模型只提出受控组件修改，不返回执行代码。

图片地址、动态数据绑定和编辑器已锁定的内容保持；额外锁定也受服务端校验，不能借AI解除。同步区块内部、循环卡片资产等继续通过原有编辑入口维护；编辑同步区块资产时AI入口暂不可用，避免一处操作影响全站。页面里的同步区块可调整其外层布局，内部内容不改写。

当前主要支持普通标题、正文、按钮文字和已有控件的受控布局/样式；可调整容器顺序、分栏、留白和三端覆盖，并按规则插入普通可编辑容器或文字。复杂组件、富文本中的内嵌内容以及不支持的操作会保留或拒绝，不把它们拆成失去绑定的固定内容。AI不替企业确认认证、产能、价格或交期，新增文字仍须人工核对。

## 撤销与历史

打开**调整记录**可查看本人在该页面的历史预览。未应用方案短期有效；已应用记录保留7天撤销入口。点击**撤销这次AI修改**只恢复该次影响的页面草稿，不更改其他页面、产品或公开发布版本。

如果该页面在应用后又被人工或其他AI调整过，系统会先阻止直接撤销，以免覆盖后续内容；其他页面或产品的正常修改不会因此被回退。撤销成功后，仍可继续手工编辑。撤销草稿不会自动回滚已经公开的版本，需要原发布流程。

可以移除不用的暂存或历史记录；已采用的页面不会删除。但移除已应用记录后，就失去该记录对应的撤销入口。网络中断、是否保存不确定时，应先重新加载服务器状态，不能自动重复付费生成。

## 恢复与设计差异

未提交的指令、范围和保留选项可沿用后台恢复机制；不会把整页数据、模型产物、图片文件或密钥写入恢复存储。恢复只打开输入工作区，不自动调用AI、应用或发布。

整站建站已扩展为六种设计布局语法：叙事留白、产品目录、视觉展示、交错图文、模块层次、大字编号。每次仍生成三个可解释的方向，并可按区块组合左右图文、堆叠、卡片或步骤布局。差异体现在原生组件结构、图文关系、列宽和节奏，生成后仍能自由编辑，不承诺全网唯一。

本轮自动化和浏览器使用本机合成模型验证流程，不能代替用户实际服务商的文案/设计质量评估。更详细的实现、验收和后续范围以执行板与专项记录为准。
