# 整站多语言翻译

管理员在「网站页面」或「全站设计」点击「AI翻译网站」，选择原语言、目标语言与页面，按需勾选页眉页脚。AI服务由站点管理员自行配置；没有模型时仍可查看配置、统一术语与已有记录，系统不会代配密钥或自动调用第三方。

## 可用范围

- 普通页面的名称、SEO标题、SEO介绍和原生编辑器文字；SEO介绍为空时，将当前站点介绍作为可译来源，只写入目标页面。
- 页面引用的共享区块、列表卡片区块、菜单、表单名称、按钮、字段说明、占位符和选项文字。
- 原生富文本中的文字、图片说明与图注；图片地址、尺寸、链接、标记与节点结构留在本机。
- 公开组件的内置说明文字通过已知 `props.labels` 写回；列表筛选与分页复用 `query.labels[目标语言]`。
- 目标语言的全站页眉、页脚与菜单。默认头尾会转换成独立原生区块，并保留原语言等价版本供以后切换默认语言；当前默认外观不因此改变。

产品、文章等动态业务记录不在普通页面翻译中重复生成。页面绑定只映射到实际已有的同语言记录，没有对应译文时保留有效原目标并明确提醒。在产品或内容管理中翻译相应资料后再核对动态展示。公司事实组件仅翻说明标签，不让模型改写地址、企业角色、复核事实或认证内容。

## 采用与撤销

生成先写本人私有候选，不修改草稿、不发布。核对电脑、平板与390px手机实际页面，可逐项对比文字。更改采用范围需要点击「更新范围预览」：从已生成内容派生新的冻结候选，不再次请求模型；采用的范围与看过的预览保持一致。

确认采用后建立独立语言页面、依赖区块、菜单及表单，仍可在原编辑器拖拽和编辑。已有目标语言布局、富文本骨架或表单字段顺序不同会拒绝错配，保留人工设计。翻译状态为待审核，按已有语言发布流程核对后发布。

未采用预览有效40分钟；采用后撤销记录保留7天。安全撤销只恢复本次对象，保留无关修改；目标被后改、增加引用、第三语言引用新建翻译组、头尾映射变化或跟踪关系被后续任务更新时拒绝危险撤销。删除私有记录不撤销已经采用的内容。

## 统一术语与更新提醒

术语按语言对持久保存，整站、产品和文章翻译共用；本次临时用词可覆盖同名统一术语。每对最多30条、全站100条，修订号防止多人覆盖。品牌、型号、SKU、占位符和数字单位受保护，不能通过长术语暗中替换。

私有绑定只追踪原文与译文指纹，源文更新会提示，不自动覆盖已审核译文。独立交付包只依靠原生页面语言组、头尾语言映射和成对节点引用，就能重新识别已有译文；缺少私有跟踪表不会重复建立整站副本。

## 资源与权限

一次最多20页、24000字符、400段文字、100个依赖对象，单次候选16MiB，用户暂存48MiB、40条总记录、12条未采用记录。模型调用前先预留完整输入和结果空间，容量不足不消费模型；超限不自动拆批、重试或收费。真实调用量由统一用量服务记录，不保存正文或密钥。

API使用同源写入、管理员权限、正文解析后的新鲜会话与事务内再次检查。合法受理模型任务后退出登录可保留本人私有结果，读取、采用和撤销仍要求重新登录；降权、禁用不予采用。预览仅允许候选中明确冻结的页面路径，禁用客户JS、禁止匿名访问并使用私有不可索引响应。

## 实现与验证

- 原生文字引擎：`src/lib/ai-site-translation.ts`。
- 资产与安全操作：`src/server/ai-site-translation-assets.ts`、`src/server/ai-site-translation.ts`。
- 术语：`src/server/ai-site-translation-glossary.ts`。
- 管理弹层：`src/components/AiSiteTranslation.tsx`。
- 接口：`/api/ai/site-translations`；预览：`/preview/~site-translation/{id}/{before|after}/{页面路径}`。
- 单元与临时SQLite流程：`tests/ai-site-translation.test.ts`。
- 隔离浏览器流程：`tests/ui/ai-site-translation.spec.ts`，使用本地合成模型，不代表真实语言质量。

SQL19增加三张私有表：候选、术语库、更新跟踪。原生头尾映射属于snapshot/renderer22，不可用旧渲染器解释新快照。升级保留原生数据及语言映射，回退前先导出站点并按项目统一SQL19回退方案处理，不手工改生产数据库。

本模块不执行真实付费模型或生产发布；真实翻译质量、长德语排版与企业术语仍需管理员配置本人模型后进行人工验收。
