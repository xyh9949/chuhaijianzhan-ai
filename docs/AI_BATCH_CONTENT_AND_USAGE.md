# 批量内容与AI用量

入口：产品管理、内容管理中的“批量AI内容”，或“站点设置 → AI服务 → 批量内容”。用量在同一区域的“用量与价格”。均由管理员操作，AI服务、模型与密钥仍由用户自行配置。

## 实际工作流程

1. 选择写作/改写或翻译，明确选择1–5条现有产品或文章及各自的字段。设置入口可以切换产品与栏目内容；业务入口默认当前类型。翻译还需选择已启用的目标语言，可填本批术语和共同要求。
2. 创建任务并生成一条样本，只发送一次模型请求。样本返回后自动暂停；生成结果只是本人私有候选，没有修改网站。
3. 核对原文、建议、事实缺口和真实页面。产品/文章需有可访问的详情模板才能进行实际页面渲染；没有模板时明确展示字段预览，不用空白页面冒充完成。
4. 认可样本后明确继续，按顺序生成其余条目；每条独立保留结果。暂停或结束会阻止下一条，已经被受理的请求仍保留私有结果。关闭、刷新和读历史都不自动发起新模型请求。
5. 每条分别勾选字段，查看对应字段组合的真实页面，确认后只保存这些字段到草稿。未选搜索标题/介绍不会随正文一起改变；不会自动发布。结果使用原生图文和字段，仍能在原产品/文章编辑器中继续编辑。
6. 每条都有撤销。仍未被后来修改的字段可回退，无关手改保留；同字段或新翻译记录后来被人工修改，会拒绝危险撤销。

共同要求真正发送给写作和翻译模型。翻译要求只控制措辞、语气，品牌、型号、数字、单位、既有图片/链接和共用术语仍由原编译器保护；要求不能让模型越过原文槽位增删事实。未选择的翻译字段仍保留原文并标为待核对，不声称整篇已经翻完。

## 请求、预览与历史边界

- 每批最多5条、每条最多12个明确字段。每人最多20批、保留7天；写作已知原文最多4 MiB，原文与冻结原生预览合计最多8 MiB，模型前拒绝超限。
- 首样本必须是当前任务中真实生成的候选，并明确确认后才能生成剩余条目。暂停不取消已经受理的收费请求，也不采用结果。
- 同一`operationId`无论失联、失败重试还是后来再次重送，均只受理一次；一个标识不能换条目。每条保留最多20次明确请求标识。失败与120秒后结果未确认的请求不会自动重试，必须说明可能再次收费并由用户决定。
- AI配置、原文、所选字段/栏目/语言上下文和共用词库在创建时冻结；变化后拒绝旧请求，避免半批更换模型或术语。写作真实预览的布局、样式或同步区块变化也会要求重新准备。
- `/preview/~batch/:job/:position/:side/:real-path`只允许本人任务中该条的真实详情路径，拒绝追加其他对象地址。`after?keys=...`只渲染选中字段，采用后不允许借查询参数扩大范围；预览关闭客户JavaScript。
- 写接口同源检查；body/params完整读取后复查会话，写事务内复查。合法受理后的模型响应允许在会话过期后保留本人私有结果；降权、停用、过期、原文冲突仍不能采用。再次读取/采用/撤销均重新鉴权。
- 任务历史显示真实内容名称和条数，可读取结果、继续核对或清理。删除任务同时清理未采用候选；已采用的普通业务内容和撤销回执继续保留，可在原编辑器管理，不因清理任务回退业务。

任务是有界的用户驱动队列，没有后台定时继续或自动重试。刷新读取到“结果未确认”时先核对历史；模型服务商可能已处理上次请求，界面不能承诺未扣费。

## 用量与估算

只记录本人从本系统发起、进入统一提供方的请求，最近30天、每人最多5000条。记录任务、请求模型、计数、图片数量、耗时、状态和可选批次ID；不保存提示词、正文、图片二进制或API密钥。外部AI客户端直接调用它自己模型的消耗不属于本站记录。

- 输入、输出和总token只用接口实际提供的非负整数，不拿字符数估token。
- `null`显示“接口未提供”，真实`0`显示0；总token为0但分项缺失时仍不推断零费用。
- 接口总量与分项合计不同，保留原值并提示；不替供应商改账。
- 价格由用户按配置模型名填写每百万输入/输出token单价及三位大写币种，每模型一种币种。不配置价格或分项缺失则无金额估算，不猜价格或汇率。
- 价格按请求时冻结，后改价格不重算历史。金额按真实输入/输出分项计算，极小正费用仍保持为正值，不能四舍五入成“零”。不同币种不合并、不换算。估算不等于供应商账单。
- 发请求前先记受理；完成统计写入失败不会丢弃合法模型输出，原“结果待确认”记录保留，不冒称成功或零费用。
- 状态“模型已响应”表示提供方请求完成，不代表内容通过审核、已采用或已发布。失败请求也可能已计费，不能用本站状态推断退款。

手机端使用清晰卡片显示模型、真实分项和估算，桌面表格默认可见总token与费用，细节可展开。价格是实例共用配置，使用记录只属于各自账号。

## 验证与维护

`tests/ai-batch-usage.test.ts`16项临时SQLite/本机mock测试覆盖：首样本闸门、顺序处理、暂停、字段采用/撤销、原文与配置保护、受保护术语及自然语言要求、真实写作子集页面、历史清理、旧标识幂等、迟到结果竞态、实际token/0/缺失、极小正金额、角色和会话边界。迟到竞争测试明确模拟另一个进程已取得新操作的持久状态；单实例提供方本身也会拒绝并行请求。

`tests/ui/ai-batch.spec.ts`为隔离浏览器流程，使用确定mock响应和真实业务API：首条样本→明确继续→处理中暂停→继续→原生页面子集对比→确认采用→撤销→用量；另测产品翻译的真实预览与新增语言记录撤销。测试不访问正式3200、不调用真实模型，存在测试文件不等于已在目标环境运行。

升级或改原写作、翻译回执、预览路由、共用术语/提供方计量时，须回归以上流程与身份边界。数据库迁移及依赖由项目统一管理；本模块复用原写作/翻译候选与撤销机制，不复制另一个正文编辑器。回滚在隔离环境使用匹配源码和私密数据备份验证，不用旧库覆盖升级后的业务内容。
