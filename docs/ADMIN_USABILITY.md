# 管理后台易用性调整

把日常任务放在前面，复杂配置按需展开。公开网站的样式和布局可在编辑器里继续调整。

## 日常使用方式

先填写资料并保存，再到发布管理确认更新。保存草稿不会自动更新公开网站。需要不同的页面布局、产品参数或网站风格时，仍可使用原有拖拽编辑、栏目设置、公共区块和高级工具。

| 区域 | 本次调整 |
| --- | --- |
| 工作台 | 用版本名称代替内部编号，直接说明保存与发布的区别。 |
| 网站页面 | 默认先填名称和网址；用途、多语言、搜索展示按需展开。修复首次打开空表单也提示未保存的问题。 |
| 产品管理 | 分类可以选择或直接输入；少用的排序、搜索、语言设置折叠，额外参数按需显示。无封面草稿显示占位提示。 |
| 内容管理 | 原“内容模型”改为日常能理解的名称，默认进入内容资料。可直接添加现成栏目或自定义栏目，栏目创建不生成假记录。 |
| 栏目设置 | 新增下拉选项自动生成独立识别代码，已有代码和选择保持。一般只需填写显示名称，技术代码在高级项中。 |
| 手机内容列表 | 用资料卡片展示名称、栏目、状态和编辑操作，解决长网址挤压标题的问题。电脑保留表格。 |
| 素材与询盘 | 简化图片说明、使用位置、导出等文字，旧询盘清理收进高级项；删除与清理仍需明确确认。 |
| 模板中心 | 没有自存模板时优先展示可选设计，保留“我的页面模板”和整站模板入口，移除重复标题。 |
| 网站外观与全站设计 | 默认先看网站顶部、底部和导航；复用样式、代码等明确标为高级用途。 |
| 拖拽编辑器 | 文字、图片等常用组件排前；内容与外观分组。数据绑定、查询、样式复用等按需展开，已有自动内容配置会提示。标题级别、尺寸和间距使用直白说明。 |
| 发布管理 | 按选择内容、检查问题、确认更新三步操作，显示已选数量。需要一起发布的资料直接给出处理入口；范围变化后必须重新检查。 |
| 站点设置 | 网站资料与常用设置排前，正式网址、语言及下载副本的说明更清楚。语言可从常用选项添加，更换主语言与服务器备份详情放在高级项。 |
| 专业工具 | 整站迁移、模板适用规则、表单、菜单、旧网址跳转等保留原功能，减少默认说明中的内部术语。成员权限和开发者权限规则不变。 |

## 数据与功能保护

- 共享的MoreSettings使用Ant Design Collapse，折叠时字段保持挂载并参与保存；出错时展开相应区域。搜索、多语言等字段不会因为没有打开而丢失。
- 产品的数字0、布尔false、已有选项值、搜索和语言资料均实际验证保留；没有替用户重写识别代码或清空配置。
- 页面未保存判断只比较固定顺序的可编辑字段，打开、挂载或展开可选项不会被误判为编辑。
- 发布默认选择、权限、部分发布、依赖检查和过期检查保留。建议按钮只改变选择范围，不保存或发布；最后仍需明确确认。
- 未修改数据库结构、公开渲染协议、依赖版本、账号权限或客户自定义页面的渲染规则。

## 后续维护

实现主要位于components/MoreSettings.tsx及各管理页面。升级Ant Design、Puck或Next后，应验证折叠字段保留、校验展开、空表单关闭、自动内容配置提示、移动端卡片、设备样式独立性和完整发布确认。优先沿用官方组件与扩展点，不修改依赖源码。
