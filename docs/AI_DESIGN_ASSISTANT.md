# AI设计助手

应用0.20.0。入口：**网站页面 → 编辑页面 → AI设计**。先点选区块时默认设计该区块；没有点选时设计整页。功能仅管理员可用，模型在**站点设置 → AI服务**由用户配置。

## 不懂排版也可以使用

输入企业做什么、客户是谁、希望达到的效果即可，例如：

> 我们做定制家具，面向海外工程采购。首页要更有商业感，让客户容易了解产品和项目经验，手机上也方便浏览。

也可以直接选择“让首页更专业”“做好产品展示”“手机上更好看”。范围、锁定及保留文字在可选项里，默认允许按要求优化内容和排版。真实企业事实仍需核对，系统不会替企业确认认证、产能或价格。

1. 点击**生成调整方案**。会先保存当前画布，使用用户配置的模型生成一个候选；网站尚未采用AI修改。
2. 查看“我对你想法的理解”：本次目标、设计决定、保留内容及需要核对的假设。
3. 查看真实前后预览，切换电脑、平板、手机，滚动检查完整页面。图片和产品内容使用候选中的真实资源及数据。
4. 不满意时直接在“还想怎么调整”继续描述。例如“保留这个布局，产品图片更突出，手机留白再紧凑一点”。选择“只调手机”可以限制本轮只修改手机样式。
5. 满意后**确认应用到草稿**。返回原编辑器继续自由拖拽；公开站点仍通过原发布流程更新。

每次生成和继续调整均主动调用一次所配模型，不自动重试或更换服务。初次生成后最多继续调整六次，达到上限可采用满意结果后从当前草稿重新设计。未配置或未启用AI时，窗口保留输入并提供统一设置入口。

## 动态产品卡片

告诉AI“重新设计产品卡片，图片更突出、参数更清楚，保留产品自动更新”。AI可把普通产品列表升级为自由卡片列表，或复制已有产品循环卡片，生成本页使用的独立设计。

卡片中的产品名称、图片、描述、材质与链接继续使用当前产品字段绑定。产品资料更新后随数据展示，不复制成固定样本正文。可使用原生容器、图片、标题、正文、按钮继续重组和调整样式。

采用后，在图层选择对应列表，点击**编辑卡片设计**，进入原拖拽编辑器。新卡片为本次候选独立创建，原共享卡片及引用它的其他页面保持。

## 手机与其他屏幕

“这次主要调整”可选择全部屏幕或一个屏幕。单屏模式只允许对应屏幕的样式调整，文字、图片引用及节点结构保持。桌面、平板样式向小屏继承时，系统会保留小屏原先的有效值；无法安全隔离的调整会明确拒绝。

需要修改页面结构、替换图片或重新设计动态卡片时选择全部屏幕，再用自然语言说明各屏幕需求。可以先完成整体设计，再单独微调手机。

## 预览与排版检查

预览按真实CSS视口渲染：电脑1280、平板768、手机390px。屏幕较小时只缩放展示外壳，网站媒体查询仍按该设备宽度执行。

切换屏幕后读取实际沙箱DOM，检查横向溢出、坏图/待加载图片、小于12px的文字、手机过小操作区域和一级标题数量。最多检查1500个相关元素，未覆盖部分明确提示。滚动后可点击**重新检查排版**。检查结果可随下一次继续调整送给模型。

这些是基础排版诊断，不是截图审美评分、全链路可用性或SEO排名保证。当前没有自动截图视觉评审或自动多轮修复；设计观感与业务表达通过真实预览和用户继续反馈确认。

## 确认、撤销与保护

- 生成、继续调整与预览不采用AI修改。连续候选始终以最初页面作对比，采用最后一版时包含前面保留的设计。
- 应用同时保存目标页面和本次生成的独立卡片，仍是草稿，不自动发布。
- 应用后七天内可从调整记录撤销，恢复最初页面并清理本次卡片。页面/卡片已有新编辑或卡片被其他地方引用时，系统拒绝直接覆盖，保留后续工作。
- 保留文字、锁定子树、范围与权限由服务端检查。候选基于旧版本时需先读取当前草稿，不能直接覆盖人工修改。
- 其他页面、产品、询盘、配置和已发布快照不随本次撤销回退。删除已应用记录会失去该记录的撤销入口。

模型按需接收所选节点、可用素材的有限元数据、可选站内链接、相关产品字段及少量匹配样本、企业公开信息和当前账号确认的依据。原始PDF/Excel、整库产品、其他页面正文、询盘、成员和密钥不会因此自动外发。

要一起调整页眉、页脚、导航和跨页风格，可打开[AI 整站设计](AI_SITE_DESIGN.md)。外部模型接入方式见[外部 AI](EXTERNAL_AI.md)。对外发布前，使用真实资料和配置的模型核对内容及布局。
