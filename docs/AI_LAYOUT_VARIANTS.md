# AI设计布局与差异说明

布局由编辑器中的原生容器、标题、正文、图片、动态产品列表和表单组成。AI 服务由用户自行配置，切换布局时可以使用现有结果。

## 六种方向

每次整站规划仍给出**三种方向，从以下六种中选择三个**，根据企业资料说明为什么适合。方向之间应体现信息组织、图文关系和内容重点，不只替换配色。

| 方向 | 实际编排 | 可考虑的使用场景 |
| --- | --- | --- |
| 叙事与留白 `editorial` | 有图时首屏文字与图片并排，特点双列，先解释再浏览 | 需要讲清业务定位、材料或合作方式的企业 |
| 产品与目录 `catalog` | 产品内容优先、规则目录和紧凑信息组，首屏纵排 | 型号/分类多，买家需要快速浏览的目录站 |
| 视觉与展示 `showcase` | 图片前置、居中大标题、纵向展示节奏 | 有真实可用视觉素材的家具、空间或设计类业务 |
| 交错与对比 `split` | 图片/文字左右交错，桌面采用1:2或2:1不等宽分栏 | 希望逐段解释产品、材料或应用，且有对应图片的业务 |
| 模块与层次 `bento` | 四列网格、不同跨列宽度的卡片、介绍与图片分组 | 卖点或应用信息较多，需要分层组织的业务 |
| 大字与编号 `minimal` | 大标题、窄幅说明、编号纵向条目和留白 | 信息精简，希望强调定位和少量明确要点的业务 |

这是设计建议，不是行业强制规则。相同企业可以选不同方向；不同企业也可以合理使用同一基础布局。文案、页面用途、资料重点和素材仍需企业确认。

## 区块也能选择自己的编排

页面方案的区块可选`layout`，不填或使用`auto`时继承整体方向。局部意图不应给所有区块套同一种排列，否则三个方向反而会趋同。

| 区块意图 | 含义 |
| --- | --- |
| `auto` | 根据当前方向编排，兼容原有未填写布局的方案 |
| `split-left` | 图片在左，文字和真实内容在右 |
| `split-right` | 图片在右，文字和真实内容在左 |
| `stacked` | 纵向编排，资料条目逐个纵排 |
| `cards` | 将已有条目分组为卡片；Bento方向使用宽窄跨列，其余使用规则卡片 |
| `steps` | 给已有条目添加01、02等阅读顺序；编号不表示真实生产流程、年限、产量或统计数据 |

未知布局会被拒绝，不接受任意HTML、CSS或外部图片网址。指定图片必须来自当前站可用的图片素材ID；已有动态产品详情、产品绑定和表单继续使用原组件。

## 缺图、窄屏和继续编辑

没有可用图片时不生成虚假工厂照，也不插入冒充真实内容的空图片框。左右图文退回文字布局；Bento可用标题/说明分组；Minimal仍以文字为主。缺图时某些方向的差异会缩小，应在预览中判断，不能声称没有资料也能得到完全不同的高质量视觉。

桌面跨列在平板、手机显式重置，正文区块移动端归一列，图片降低高度，留白另设三端值；品牌导航在手机保留两列链接。结果仍为普通Puck节点，可以拖拽、移动、改字、换图、调整分栏和三端样式。已有页面和锁定内容受原保护规则约束，整站生成不会借换方向覆盖旧站。

## 预览中的差异标记

`analyzeAiDesignDifference`在本机比较修改前后保存的数据，分别标出结构、布局、字体、配色、文案变化：

- 结构比较组件类型树、内容插槽及同父级阅读顺序，忽略随机节点ID；同形容器使用内容锚点识别重排。
- 布局、字体与颜色比较三端已保存样式，并考虑现有组件的默认值；这是数据比较，不是像素级截图比较，也不能代替手机预览。
- 文案独立比较静态可见文字；仅移动原文不当作重新写了内容。
- 如果只换了颜色，会明确提示结构、排版和文案保持，避免把换色包装成完全不同的设计。

站内重复提醒只比较**当前实例传入的其他页面**，不抓取互联网、不上传客户站点、不建立跨客户样本库。调用方应排除当前页。仅在两页都具备至少240字符静态正文、两个不同的Heading组件，且标题顺序与组件结构相同、正文三字片段重合率不低于0.9、长度比例不低于0.85时提示。共同页眉/页脚/导航跳过，动态绑定占位文字不算正文，包含ProductDetail的详情模板不参与，以免将共用模板误判成抄袭。

这个保守规则会漏掉某些同义改写、RichText独立文章或仅局部相似的页面。每次最多比较200个传入页面、列出5条提示；单页深度24/节点1500，重复比较正文上限60000字符。超过范围不据此宣称不同。提醒只帮助人核对页面用途，不阻止保存，不给0–100唯一性分数，也不代表版权判断。

优先使用实际页面预览查看手机端的阅读顺序、图片裁切和主按钮，再决定是否应用。
