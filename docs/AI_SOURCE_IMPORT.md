# PDF与Excel快速建站指南

入口：**AI快速建站 → 导入PDF / Excel**。本功能由管理员操作；其他成员仍按现有页面和产品权限工作。

## 推荐顺序

1. 上传公司PDF，勾选需要的页码。查看原文后，可以直接摘录，也可以明确点击**用我的AI整理公司资料**。
2. 逐项核对公司名称、说明、行业等。已有内容默认保留，只有主动勾选后才替换；没有依据的字段留空，再手工补齐。
3. 上传产品`.xlsx`，选择产品工作表和表头行，核对产品名称、型号、分类等对应的列。
4. 在表格中修改单元格、取消不需要的行，点击**检查选中的产品**。检查不调用AI，也不新增产品。
5. 查看实际准备写入的产品与参数；检查通过后明确点击**确认新增产品草稿**。不覆盖旧产品，不自动发布。
6. 返回建站，补齐主要客户、市场等缺失资料。最多使用本批前20个产品参与规划；完整产品目录仍使用真实已导入产品。确认方案和预览后保存草稿，继续用原拖拽编辑器修改和发布。

## 资料与AI

上传只在运行网站的服务器本机提取，不调用模型。原件、提取文字和图片按当前账号私有保存2小时，供按需离线OCR、抽图和核对，不会变成公开下载素材。可以使用“下载原文件核对”鉴权附件入口，其他账号和访客无权读取。可主动移除；到期立即拒绝访问，物理文件在本人后续主动写操作时清理。删除来源会撤回未确认的派生合并，已保存产品和已确认资料回执仍保留。

AI连接仍由管理员自行配置服务地址、模型和密钥。只有点击**用我的AI整理公司资料**才会将选中页文字与页码发送给该服务，并使用自己的模型额度；最多24,000字，超过时请减少页数。结果提供页码与原文依据，需核对后再使用。模型失败不自动重试或切换服务。

不配置AI也能上传、查看PDF、摘录和导入Excel。点击**把选中页作为说明草稿**可编辑摘录后带回建站表单。说明上限6,000字，超出时必须自己删减，不会静默截断。整站生成只发送已确认的短资料及界面说明的产品、素材信息，不自动携带完整导入原文。

## 文件要求

- 每份最多10 MB。PDF最多100页、150,000字；默认读取已有文字层，扫描页可明确选择1–5页启动中文、英文或中英混合本机OCR。文字、数字、单位和阅读顺序可能出错，识别稿逐页标为待核对，并保留原文字层。
- Excel只支持`.xlsx`。旧`.xls`请先在Excel中另存为`.xlsx`。最多10个工作表、全文件合计1,000个非空行、每表64列，单元格最多6,000字；超过限制会提示重新整理文件。
- 隐藏工作表不能选用，隐藏行列默认不导入。需要使用时，在原文件取消隐藏并重新上传。
- 公式仅使用文件内已有的缓存显示值，不计算公式、不执行宏或外部链接。无缓存时保留为缺失，不猜成0。请先在Excel中计算并保存；文本编号的前导零、数值0、FALSE和单位按提取显示值保留，仍需人工核对。
- 不自动下载图片网址。可主动提取PDF实际嵌入位图或Excel真实单元格锚定图片，私有缩略图逐张核对、明确选择后才进入原素材中心。PDF整页扫描和图形片段有说明，不把OCR页面渲染图当产品原图。没有提取的格式和范围会给出提示。

## 扫描识别与资料图片

在当前文件的“扫描识别与资料图片”区域，PDF选择本次页码和语言，可以只识别文字、只提取图片或两项一起处理；Excel点击“提取工作簿图片”。处理完全使用随服务安装的本地依赖，不调用AI接口，也不访问CDN或文件内的网址。旧暂存记录未保留原件时需重新上传。

每次PDF处理1–5页，单页最多600万像素、长边2600像素；每次90秒看门狗并支持停止处理。提取最多40张、每张2 MiB、本次图片总24 MiB；单份累计最多80张。格式不支持、复杂蒙版、没有锚点或超限的图片会说明未提取，不保证还原全部设计元素。本人私有原件和图片合计80 MiB。

Excel图片展示真实工作表、行列及隐藏状态；与产品行对应只是建议。先明确选入素材中心，再在产品行选择已采用的来源图片，检查实际准备写入的产品后确认新增。不勾选则产品仍无图，系统不根据相邻位置自行确认配图。采用图片后也能在原素材中心和产品编辑器继续管理。

## 合并多份资料

点击“合并多份资料”，从最多5份PDF或Excel中选明确页码/表行：每文件PDF最多5页，Excel最多20个可见行。证据保留文件名、原页/表/行和OCR/公式缓存说明，不混入未选内容、隐藏行列或把零值当缺失。

各建站字段分别选择保留、忽略、用一个来源替换或将几条证据追加；公司名称只能明确选一个来源。每项文字可以人工整理，同时保留原文出处并标识改写。不同来源有矛盾时必须自己取舍，不会最后上传的文件自动覆盖旧值，也不自动猜企业认证、市场或产能。

准备后先看前后对比，确认才将精确字段带回建站表单，不直接写网站或发布。来源或当前表单变化后旧预览拒绝采用。确认回执保留7天供撤销；撤销只恢复本次字段，保留无关手改，同字段后来改过则提示人工核对，不覆盖新工作。多来源合并本身不调用模型；仍可在原单份PDF流程主动使用自己配置的AI整理，再核对使用。

## 产品核对与保存

在 **产品管理 → 按型号更新** 可用新版 `.xlsx` 维护现有产品。工作表的型号列用于匹配，首尾空白和字母大小写不影响匹配，文本编号的前导零原样识别。只建议识别型号列，站长要手工选择更新列和行。空值、未映射列和未勾选的行保留当前值，陌生或重复型号会标出原行号，可取消勾选后再次检查。产品 ID、型号、语言、网址和未选择的字段继续沿用。

可更新名称、分类、材质、介绍、搜索资料、排序和所选参数组的基础字段。数字可以用 `0`，布尔用 `true` 或 `false`，选项请用字段中保存的值，多选用 JSON 文本数组。表内图片需先提取并明确选入素材库，再按行选择新封面，旧相册其他图片继续按原顺序保留。预览列出实际改变的产品及字段前后差异，核对后再确认写入草稿。预检有效期五分钟，预检后其他窗口修改草稿会要求重新核对。

保存后在同一入口的 **最近更新** 查看本人回执。七天内可撤销已写过的字段，包括重新打开页面、原文件过期或已移除后的情况。后来对同一产品的其他字段编辑会保留。同一字段后来被改动、产品被移除或参数组无法对齐时，会暂停整批撤销。本流程只使用已上传文件与当前草稿，更新后的内容仍走正常发布预检与确认。

必须指定**产品名称**和**产品型号 / 编号**。不要把同一列同时对应两个字段。可以修改已映射的单元格；取消勾选即跳过该行。每次最多新增500个产品，可使用**选择前500行 / 选择下一批**分批检查和保存。

**其他参数与搜索资料**是可选项。默认将所有未映射列按列名附加到产品介绍中，以免尺寸、包装等参数丢失；这些内容可能展示在网站，含内部备注时请取消该选项，或清理原表后重传。保存前展开**查看实际准备写入的产品与参数**核对。

重复型号、重复网址短名、缺少名称或型号等会拒绝整批，不会部分写入或覆盖已有产品。先改表格、跳过问题行，再重新检查。

检查结果5分钟有效，来源资料2小时有效。超过时间或其他人修改了网站时，读取最新工作区并重新检查即可；这些操作不调用AI。保存网络中断、结果不确定时，可以再次确认同一批检查结果，服务器按原回执返回，避免同一批重复创建。重新上传或刷新后再次选到已保存产品时，重复型号检查仍会阻止重复新增。

## 关闭与恢复

临时原文、单元格改值和未使用的 AI 整理结果不写入浏览器恢复存储。Excel 核对时从离开提示选择**保留输入并离开**，会把人工改值暂存在本人私有资料中，期限与原文件相同。当前标签页刷新后凭回执恢复，仍需检查并明确导入。直接刷新只能恢复已经暂存的改值和当前映射。尚未使用的 PDF 整理稿请先带回建站表单；多来源合并凭候选 ID 读取已冻结结果。短期资料过期后需重新上传。

已经明确使用的短建站资料和最多20个优先产品ID沿用原建站草稿恢复。API密钥不进入恢复草稿。恢复不自动调用模型、新增产品或发布网站。

仍不支持旧`.xls`、识别图片表格为结构化Excel、恢复任意PDF矢量插画或根据多份文件自动确认企业事实；不会按资料自动改写所有已有产品。部署及验证细节见 [资料增强实现](AI_SOURCE_ENHANCEMENT.md)。
