# 网站表单与询盘

## 操作

管理员在“全站设计 → 网站表单”创建字段，也可在拖拽编辑器的Form组件中新建/选择定义。名称、排序、提示、必填、字符上限、下拉选项、询盘资料对应项均可配置。字段ID保持稳定；历史询盘保留提交当时的标签、类型、选项显示值。

Form组件负责外观：桌面/平板/手机分栏、间距、外框、文字、输入框、提交按钮和整行字段分别可设。定义供多处引用，各处外观独立。定义保存不自动发布；发布页面时明确勾选“网站表单”。删除仍被引用的定义会被拒绝。

预览为演示，不产生询盘；公开站点需JavaScript获得提交会话。无脚本时显示说明。匿名附件上传不开放。访客成功提示只表示数据库收到提交，不代表邮件送达或承诺回复时间。

后台询盘可刷新、查看完整答案/来源、修改状态和处理备注、按当前筛选导出CSV。编辑员可处理和导出；只读成员只能查看；删除、通知重试和保留策略仅管理员。备注冲突保留当前输入，由用户核对最新内容。

## 多产品询价

管理员可在「全站设计 → 网站表单」打开目标表单的「多产品询价」开关。既有表单默认关闭。保存后预览包含该表单的页面，确认时将「网站表单」纳入发布范围，并确认该语言至少有一件已发布产品。使用此表单的公开站点可以从产品目录及详情选款，也可直接在询价表单添加产品。草稿和发布预览只演示操作。

每份清单可选 1～20 款不同产品。每款填写 1～1,000,000 件的整数数量，可附 500 字以内的规格或要求。服务端根据表单所在语言和提交时所绑定的发布版核对每款商品，保存当时的型号、名称、数量和要求。以后更改产品或回退网站版本，已接收清单仍保留原值。

整份清单作为一条询盘进入后台、导出和已启用的邮件通知。同一会话和相同内容重试返回原回执，只创建一条询盘和一个通知任务。启用真实邮件后，实际收件箱可单独核对。

## 接收与通知

只接受当前公开版本中已启用且实际出现在来源页面的表单。服务器复核来源Origin、签名和时间、蜜罐、类型/长度/必填、已发布产品及选项；不接受客户端收件邮箱。访客限流独立于回执，重复提交同一会话和答案只返回已有回执；更改已接收答案会报冲突。

询盘、幂等回执、通知任务同事务写入。通知失败不会撤销询盘。发生网络错误且无法确认是否已接收时，前台保留原答案和会话，重试原请求；不会自动换会话重复收件。

服务器环境见`.env.example`。默认`none`，未配置时仍可收件，后台显示“未配置”。`mock`使用Nodemailer JSON transport，只在进程内模拟；后台明确标示模拟成功。`smtp`为真实邮件，必须单独配置并授权外发；凭据和固定收件人不进入网站设置、快照或前台会话。访客邮箱仅作验证后的reply-to，消息为纯文本。

Node服务启动自动恢复队列；2秒轮询，单任务120秒租约，最多5次尝试，30秒起指数退避，管理员可显式重试。SMTP接受表示服务器已接收发送请求，不保证进入收件箱。发送后进程崩溃或部分收件人拒绝可能重投，属于至少一次投递语义。仅保存经过白名单处理的错误码，不暴露SMTP原始错误或密码。服务停止时任务保留，下次启动继续；非持久Node/短时serverless实例不属于当前受支持的worker部署形态。

## 个人资料与版本

协议10，兼容历史1–9；使用新增运行表，无破坏性迁移。表单定义进入不可变网站快照，询盘、通知、幂等回执和保留策略不进入快照。页面发布回滚、草稿恢复不会覆盖这些运行资料。旧人工录入询盘保留，人工录入不会自动创建网站通知。

保留期限默认0，表示未设清理期限。管理员可设1–3650天；不会自动删除。清理先生成预览，5分钟内按相同策略版本、记录ID和记录版本确认，每批最多1000条。中途记录变化或正在投递会拒绝清理。确认删除永久移除所选询盘及关联通知和回执，不回收网站版本。实际经营者决定期限，应用不替其作法律判断。删除回执后不再保留原提交的幂等确认。

CSV为UTF-8 BOM，日期UTC，限制单次10000条；以公式前缀开头的文本加单引号并正确引用，避免表格软件公式执行。

## 升级检查

升级Next/Nodemailer后验证instrumentation只在Node服务启动、构建不发信、重启接续、租约/重试/错误脱敏、模拟与真实状态区分。升级Ant/Puck后回归表单字段编辑、三端样式、演示沙箱、失联重试、并发备注、显式表单发布及旧版本恢复。降级应恢复对应版本的实例备份，不让旧程序写新协议数据库。
