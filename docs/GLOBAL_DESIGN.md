# 全站设计 · 0.4

## 同步区块和页眉页脚

在后台「全站设计 → 同步区块」创建区块，点击编辑进入原有拖拽画布。页面与区块通过顶部下拉切换，均支持三端布局、样式和撤销。区块只保存一份内容，页面插入「同步区块」元素并选中它后建立引用；复制区块则创建独立资产，之后互不自动同步。

「全站设计 → 页眉页脚」可选原有默认布局、同步区块或隐藏。可创建页眉/页脚基础结构，再进入编辑器拖拽修改，最后选择对应区块。基础结构只包含中性占位文字，应替换为客户资料与实际页面链接。页面设置可单独隐藏页眉或页脚；旧页面的“隐藏全站页眉与页脚”继续生效，恢复为显示后才采用单项设置。

区块内容在页面画布内作为完整引用展示；需修改内部元素时，切换到该区块编辑。可以嵌套引用，最多 8 层；循环引用和非空悬空引用无法保存。新增引用尚未选择区块时允许暂存，但不能发布。使用范围列出直接/间接页面、其他区块及头尾引用；仍被使用时必须先解除引用再删除。

### 统一旧 AI 页面

在「全站设计 → 页眉页脚」点「同步旧 AI 页面」，选择曾由 AI 创建的一页。系统会核对同一次生成的页面与详情模板。可让这组页面共用自己的头尾和菜单，也可明确改用网站现有的全站头尾。尚未配置全站头尾的单语言根站可将这组布局设为全站默认，预览会列出一并受影响的页面。

如这组页面有旧版产品目录，可勾选「同时开启旧 AI 产品目录的搜索、分类和分页」。先查看实际前后效果，再确认保存到草稿。已手工分叉的头尾、锁定或启用自定义代码的页面会给出提示，可继续从原编辑器维护。采用后可在「近期同步记录」撤销，保存发布仍通过原发布管理。

## CSS / JavaScript

管理员在「自定义代码」选择整个网站或具体页面。CSS 和 JS 各有启用开关；填写正文，不添加 style/script 标签。保存前检查启用代码的 JavaScript 语法，检查不会运行服务器代码。关闭的未完成 JS 可保存，启用时需修正错误。每份 CSS/JS 限 100 KB，全部代码合计 1 MB。CSS 按浏览器规则解释，不提供完整 CSS 静态诊断。

全站代码先加载，单页代码随后加载，按页面 ID 绑定；动态产品详情模板的单页代码应用于该模板的所有产品 URL。两个 JS 片段使用独立函数执行，共享数据请显式使用 window。正式网站在页面交互就绪后加载 JS，可直接查询 DOM；不要只依赖此前可能已触发的 DOMContentLoaded。暂不支持 npm 导入、TypeScript 编译或模块打包。同步执行错误不会阻止后续片段；异步逻辑错误仍需浏览器开发者工具排查。

可用的稳定选择器：

```css
/* 当前页面；ID 可在页面数据或浏览器元素中查看 */
.editor-site[data-page-id="home"] { background: #f7f8fa; }
/* 同一个区块在所有引用处；ID 来自区块资产 */
[data-shared-block-id="block-example"] .editor-site-heading { color: #163652 !important; }
.site-header { border-bottom: 1px solid #e5e9ef; }
.site-footer { padding-bottom: 24px; }
```

组件可视化样式中存在内联样式及高优先级规则，覆盖时按 CSS 优先级选择合适选择器或 !important。区块内部节点 ID 在渲染时按实例隔离，避免同页多个引用互相覆盖；不要依赖生成的实例 ID。

## 保存、预览、发布

1. 编辑区块或头尾时保存到草稿。代码需点击「保存代码」；切换页面、导航、退出登录或刷新时保护未保存输入。
2. 「完整预览」展示已保存草稿、同步布局和启用代码。Puck 画布不注入自由 CSS/JS，完整效果以草稿预览为准。
3. 发布管理明确勾选同步区块、全站页眉页脚、全部自定义代码以及普通页面/产品范围。首次使用的新区块和嵌套依赖需一并选择。选择代码即发布全站与所有已选入最终版本的页面代码，不代表只发布本次勾选页面的代码。
4. 点「检查所选内容」，查看受影响页面。更新已引用区块会影响其他未勾选页面；未选择的区块、布局、内容和代码沿用当前公开版本。
5. 检查通过后点「预览本次发布内容」，在新标签页点开导航、目录、详情和询盘表单。它读取本次选中内容与当前公开版本组成的网站，旧地址跳转也留在该预览中。表单只提供演示，客户 JavaScript 在此预览禁用。链接由同一登录管理员打开，20 分钟内有效。改选范围时，发布窗口立即收起原入口；已打开的标签页仍对应之前检查的组合。重新检查会替换原链接。草稿、当前公开版本变化或服务重启后同样需重新检查。
6. 点「确认更新网站」后，访客读取完整不可变快照。仅切换历史公开版本不会改草稿；恢复历史草稿可选择区块、布局和代码，代码恢复替换整套代码（只保留当前存在页面的条目），仅管理员可操作。恢复后仍需另行发布才更新访客站点。

完整草稿预览使用仅 allow-scripts、无同源权限的 iframe，客户代码不注入后台父文档。站内链接留在私有 /preview 范围；外链、邮件、弹窗及依赖同源存储的第三方功能须在隔离验收站或正式站验证。私有图片由登录父层转为图片数据，未向代码传递账号或会话。该设计依据浏览器 [iframe sandbox 行为](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)。

发布代码按站点管理员提供的代码执行，拥有访客页面的正常浏览器能力。后台入口仍不加载客户代码；这不等于任意第三方 JS 已接受安全审计。需使用有权使用且来源可信的脚本。当前交付没有额外依赖外部代码服务。

## 数据、维护和回退

新增可选字段：sharedBlocks=[{id,name,data,updated}]；siteLayout={header,footer}，每项 mode 为 default/block/hidden、blockId 为区块 ID；customCode={global,pages}，每份包含 css/js/cssEnabled/jsEnabled。普通页面 JSON 中的 SharedBlock 节点只保存 blockId 与实例样式。root.headerMode/footerMode 可为 inherit/hidden。

0.4 发布使用 schemaVersion=2、rendererVersion=2；0.5 内容模型版新发布为 3，继续读取旧版本 1/2。现有客户数据不批量改写，没有新增第三方依赖或依赖源码补丁。共享区块内的图片、断点背景图，以及代码中直接引用的 /api/media/<ID> 均纳入引用保护和快照素材检查；动态拼接出来的图片路径不能静态分析，应在页面/区块中显式引用素材。

升级前按 DEPLOYMENT 备份源码、SQLite 和媒体，不覆盖 data 与 .env.local。先在独立副本跑 build、typecheck、npm test、test:http，并检查旧默认头尾、新同步引用、三端样式、隔离预览、代码开关与版本恢复。回退应用时恢复同版本的数据备份，禁止旧程序覆盖新结构。公开代码资产按发布 ID 提供并长期缓存；切换版本会使用不同资源 URL。
