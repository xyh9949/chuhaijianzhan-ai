# SEO诊断和搜索数据建议

0.16.0，AB-07。诊断只读取当前草稿和已保存的搜索报告，不爬取外部网站、不调用AI、不修改网站或发布。AI分析、修改预览和确认使用入口的操作规则另见本轮SEO工作区指南。

## 能检查什么

- **搜索标题和描述**：区分显式设置与实际后备文字。没有单独设置SEO标题但正在使用页面/产品名称，不当成没有标题；描述按产品介绍、详情模板和网站简介的真实优先级检查。
- **一级标题和图片说明**：检查普通控件、富文本、真实产品/内容绑定、同步区块及可解析列表卡片。字号大不等于H1。装饰图片可以有意使用空alt，所以提示人工核对，不把每个空alt判成错误。
- **站内链接和入口**：读取按钮、导航、实际记录链接、语言切换器和有效重定向。不为没有详情模板的产品/内容造URL。外部网址不请求HTTP状态，不推断外链失效；动态筛选/分页及自定义JS可能有额外入口。
- **相同标题、描述或长正文**：只在可索引的实际页面间提示核对用途。共用规格、认证原文等真实内容不必为了去重而改事实，没有抄袭或唯一性分数。
- **正式网址和noindex**：未配置有效正式源地址时提示补齐，不能靠请求Host猜域名。明确noindex单列为信息并保留意图，不自动解除，也不为这些页面给搜索数据优化机会。

可检查静态页面，以及有真实网址的产品、新闻/案例等独立内容。动态模板本身没有独立URL，模板实例会按实际记录和条件模板解析。检查的是当前草稿预览，不表示公开网站已经更新、Google已经收录，或者线上HTTP状态与草稿相同。

未知扩展、旧非空插槽或递归区块可能有额外语义；这类情况不会把不认识的动态内容当作确定空H1。复杂脚本插入的DOM和自定义CSS最终显示仍需实际预览核对。

## 数据驱动的建议如何产生

Google Search Console的展示、点击、点击率和平均位置是该属性、日期、国家/设备范围中的搜索实绩，不是访客、询盘或转化数，也不是“当前固定排名”。每条建议保留报告ID、原行号、日期、时区、过滤范围和部分覆盖标记。

本轮筛选规则是可解释的工具启发式：

1. 单条查询达到100次展示但0点击时，提醒核对标题和搜索意图。100是本工具的筛选门槛，不是Google或行业CTR标准。
2. 单条查询达到50次展示且报告平均位置在5–20之间时，提醒核对内容是否完整回应需求。不承诺修改后上升，也不把平均位置当即时SERP。
3. 同一报告中的查询关联到多个本站页面时，建议核对页面各自用途和内链。它可能是正常的不同意图，不直接判为关键词蚕食。

同一来源、属性、国家/设备或地区/语言范围只使用最新报告，避免把重叠日期累加。不同范围和不同来源不合成为一个虚假总量。Google可能省略隐私查询、只返回部分数据；返回空行不能推断为全站流量为0。报告中的跨域、带参数或无法匹配的页面不会强行对应到某个CMS单页。

关键词接口/CSV中的月均量是供应商或用户提供的**估计**，不是本站的点击实绩。`null`显示缺失，数值0仍是明确的零；付费广告竞争和竞争指数不等于自然SEO难度，CPC按报告币种保留。CSV来源由上传者自述，未联网核验；模拟环境报告会明确标记为模拟。

关键词与页面的文本匹配只提供人工评估线索。只有一个页面明显匹配、关键词尚未出现在有效搜索标题、且有正的估计月均量时，才提示可以评估标题；仅按来源与目标声明的基础语言匹配，异语言或未注明语言的关键词不用于页面机会，并在覆盖说明中标注，不从国家猜语言。不会自动插词、推断产品卖点或把相关性推断当成事实。

## 范围和容量

- 每次最多检查500个目标，返回实际检查数与总数；模板/无路由对象仍明确标注不适用。
- 每页最多1500节点、正文累计5万字符，共享展开深度8，全次最多10万节点。达到限制时标记部分覆盖，不把剩余内容当空白或作确定性重复判断。
- 最多展示1200项问题，优先保留错误、警告和搜索机会；其余明确为部分覆盖。
- 搜索机会最多处理最近20份不同范围的报告、合计20000行。关键词机会额外限制1000条，每页文本相关匹配最多8000字符；完整原文和原报告不删改，未匹配不代表没有相关内容。

限制、未同步、来源省略和真实0分别呈现，不靠AI填补数据。诊断不解除noindex、不改URL、不建重定向、不改正文或搜索设置；采用任何修改仍需本轮预览、确认与撤销机制。

## 与Google展示的区别

页面提供的标题和描述只是搜索引擎可能采用的来源，Google可以改写或选择不同片段。工具中的70字标题和180字描述仅为阅读提醒线，不能当作Google硬限制、排名扣分或完整显示保证。官方说明：[标题链接](https://developers.google.com/search/docs/appearance/title-link)、[搜索摘要](https://developers.google.com/search/docs/appearance/snippet)。

纯函数实现：`src/lib/seo-diagnostics.ts`。本轮14项聚焦回归覆盖实际路由/后备内容、动态绑定/条件模板/共享区块、语言内链/关键词基础语言、noindex、搜索范围/原行号、0与缺失、来源标记以及容量，均使用合成内容，没有调用真实账号或收费接口。
