# 内容模型与动态绑定 · 0.5

## 操作顺序

1. 管理员打开「内容模型」，新建模型并选择用途：产品扩展，或独立内容。前者扩充现有产品，后者可管理案例、团队、认证等资料。
2. 添加字段，设置名称、标识、类型、必填规则、数值范围或选项。保存后字段标识和类型固定；要改类型，建立新字段、迁移值和绑定，再清理旧字段。
3. 产品编辑中选择产品模型并填写扩展信息；独立内容在「内容记录」页填写。记录标题为内置字段，无需重复建立。
4. 在拖拽编辑器选择标题、文本、图片或按钮，打开内容属性中的动态绑定。选择产品/独立内容、固定记录/当前记录、模型及字段。解除绑定后恢复组件原来的静态内容。
5. 普通页面使用「当前记录」时，在页面属性中选择默认内容记录。产品详情模板使用当前产品绑定后，公开 `/products/<产品ID>` 会自动读取对应产品；编辑样本不会固定所有产品。
6. 需要列表时，拖入「内容列表」，选择来源、模型以及标题、说明、图片、链接的字段映射，设置数量与桌面/手机列数。产品详情组件也可直接展示已填的扩展规格。
7. 保存并预览。发布时明确勾选模型、产品/内容记录及使用它们的页面或同步区块，检查通过后发布。更新已上线内容时可只选择变化的记录；未选择部分保留原公开版本。

## 字段规则

| 类型 | 保存和展示规则 |
| --- | --- |
| 单行/多行文本 | 以文本节点输出，不作为 HTML 执行 |
| 数字 | 可设置最小值、最大值和单位；0 是有效值 |
| 是/否 | 未填写、是、否分开保存；公开展示 Yes / No |
| 日期 | 有效日历日期，YYYY-MM-DD |
| 单选/多选 | 保存稳定选项值，展示选项名称 |
| 图片/图片集 | 从素材库选择；图片集最多 20 张；绑定单张图片时取第一张 |
| 链接 | 校验允许的链接协议；可以绑定按钮地址 |

草稿允许暂时缺少必填字段，发布时必须填写。字段值保存到字段 ID 下，不会因修改展示名称而丢失。删除仍有内容值或动态引用的字段/模型会被拒绝；先移除相关值和引用。修改选项或范围也不能让当前非空值失效。历史版本仍保留原模型与内容。

切换产品模型会清空该产品的旧扩展值，界面会提示；基础产品信息保留，直到点击保存才写入数据库。没有选择模型的旧产品继续使用基础信息和原有规格。

## 动态展示

- 标题、正文和图片说明可绑定兼容的文本、数字、日期、布尔及选项字段。
- 图片地址只能绑定图片/图片集；按钮地址只能绑定链接或产品内置详情链接。
- 缺少记录或字段值时使用显式设置的后备内容；不把原静态值当作隐藏后备值。
- 固定绑定适合指定案例或产品；当前记录绑定适合复用模板。同步区块继承调用页面的上下文，其编辑样本不会覆盖真实产品。
- 内容列表读取当前快照中的记录，产品列表可按产品模型筛选，独立内容列表必须选模型。列数及卡片尺寸遵循已有响应式编辑规则。
- 发布校验会展开页面、同步区块和统一头尾，检查模型、记录、字段兼容性和素材。页面绑定不会自动把草稿模型或记录带上线。

0.6 已增加独立内容详情模板和循环列表：模型可关联自动生成页面的模板，卡片可使用容器及组件自由设计。原有内容列表仍采用字段映射。具体见 CONTENT_TEMPLATES.md；当前记录仍不是关系字段、查询表达式或代码模板语言。

## 权限、发布与恢复

管理员可以定义模型、修改结构、发布及恢复模型。编辑者可以维护产品和独立内容草稿、绑定页面；只读成员不能保存。服务端执行权限和字段校验，按钮禁用不是唯一限制。

模型结构与内容都保存在不可变发布快照中，访客不读取后台草稿。部分发布针对最终公开组合校验：例如只修改模型必填规则而未更新旧公开产品时，旧产品也必须满足新规则，否则拒绝发布。恢复公开版本不会覆盖草稿；选择恢复模型/产品/内容记录到草稿后仍需重新发布。

发布删除也必须明确勾选，草稿删除不自动下线。选择恢复时须包含兼容的模型和记录，不能留下悬空引用。历史详情按历史模型解释历史字段，而不是套用当前字段定义。

## 数据与升级

0.5 引入 schemaVersion=3、rendererVersion=3；0.6 新发布为 4，继续读取版本 1/2/3。草稿新增可选 `contentModels` 与 `contentEntries`，产品新增可选 `modelId` 与 `customFields`；不批量改写旧数据，无破坏性数据库迁移，无新增第三方依赖。

编辑器绑定保存在 `props.bindings`，页面上下文在 `root.props.bindingContext`，列表映射在 ContentList 属性中。字段定义、验证及展示格式分别在 `lib/content-models.ts` 和 `lib/content-binding.ts`；服务端最终候选校验负责跨页面/记录/发布依赖。

升级前备份源码、数据库、媒体和环境配置。回退应用需同时恢复匹配的旧数据备份，不能让 0.4 或更旧程序写入 0.5 数据。升级 Next/Puck/Ant 后至少复测：模型表单、0/false、素材绑定、模板当前记录、共享区块上下文、部分发布依赖、历史恢复和手机布局。
