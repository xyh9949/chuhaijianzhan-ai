# 搜索优化工作台

入口：管理后台 → **搜索优化**，管理员可用。普通编辑成员仍按原页面、产品和内容权限工作。

这里分为三步：先检查哪里可以改，再读取自己的搜索数据，最后准备并审核修改。没有“SEO满分”或排名保证；诊断、数据同步、AI建议和发布是不同的动作。

## 先看待优化

**待优化**列出站内确定问题、建议检查、数据提示和说明。可以筛选类型、搜索内容名称，点击**查看依据**看来源、日期、国家/语言、时区和覆盖范围。

静态诊断不调用模型，不修改网站。**准备优化**只进入搜索标题和介绍的编辑；需要改正文、图片或布局时，从原编辑入口继续，原拖拽能力保持。收录开关、网址和动态绑定不会被搜索字段建议自动更改。

计数是当前检查范围内的项目数量，不是网站质量分。部分内容没有可解析的动态上下文或本次检查达到上限时，会说明覆盖；未检查不能当作已通过。

## 连接自己的接口

打开**连接数据与接口**。密钥只在当前输入框中填写，保存后不回显，也不写入公开网站、分发包或浏览器恢复。未保存的密钥在刷新后需要重新填写。

- Google：在自己的Google Cloud项目启用Search Console API，创建网页应用OAuth客户端，把界面提供的回调地址原样登记，保存客户端ID和密钥，再主动前往Google授权。只申请读取权限。授权回来后，读取并选择自己的已验证网站，保存后再同步。
- 关键词：当前接DataForSEO Google Ads Search Volume，填写自己的API登录名和API密码。保存配置不会查询或收费；点击查询还会先要求确认可能消耗自己的供应商额度。
- AI：统一使用**站点设置 → AI服务**中自行配置的模型。未配置AI也能诊断、读数据、手工准备标题与介绍并预览。只有点击**用我的AI建议**才调用自己的模型。

Google项目测试用户、应用审核、网站验证和网络可达条件由部署者自己的账号决定；本系统不提供公共账号、密钥或接口额度。断开Google只清除本实例保存的连接，不表示撤销Google账号中其他应用或全局授权。

## Google搜索表现

选择网站、日期，可以展开国家/设备筛选，然后主动点击**同步这段时间的数据**。默认取已处理完成的数据，日期按Google的America/Los_Angeles口径；最近日期可能尚未齐全。

每份已保存报告保留原始网站、日期、筛选、读取时间和返回范围。选择旧报告不会重新请求Google；修改连接设置后查看历史报告，应按当时的范围理解。

AI参考报告选择器也会标记“历史连接报告”，并列出原网站、设备、地区、语言、日期和时区。历史报告可作为有出处的参考，但不能当作当前连接的新数据；人工CSV按其上传时填写的来源范围理解。

点击是Google搜索结果的点击，展现是Google搜索结果的展示，不能当作网站访客、询盘或转化。上方合计只汇总当前返回的页面/搜索词记录，不能当完整网站总量。Google可能因隐私、查询条件或API范围省略部分记录，因此“没有返回数据”与真实数值0不同。

能够匹配到本实例内容的页面可点击**优化这条内容**；未匹配的地址只保留为报告，不会自动创建页面或修改其他网站。

## 关键词研究

填写1～100个关键词，可每行一个，重复词会合并。选择地区和语言；内置美国代码2840已按官方文档核对，其他地区需按供应商官方列表填写代码，不凭国家名称猜编号。高级选项可指定数据日期，留空按供应商返回口径显示。

确认查询会发送一次请求，不自动重试。供应商可能已接收超时请求并计费，结果不明时先读取已保存报告，不连续重复点击。

搜索量是供应商基于Google Ads的**估计月均值**；广告竞争不是自然SEO难度，CPC单位为USD。缺失显示“未提供”，0仍显示0，不用AI补数字。

也可以下载CSV格式示例，导入已有关键词报告。最多1000行、2MiB，至少包含`keyword`列；其他列可留空。需要填写真实来源名称、来源说明网址、日期、国家和语言。CPC不是美元时先转换成USD或留空。CSV来源由上传者提供，系统未联网核实；报告会明确标记为人工导入。原文件只在当前窗口内存保留，刷新需重选，不进入浏览器恢复草稿。

## 预览、确认和撤销

1. 从诊断或Google报告选择一条内容，填写**搜索结果标题**和**搜索结果介绍**。留空会沿用已有内容的默认值。
2. 点击**预览这次修改（不调用AI）**，查看前后搜索展示示意。Google可能改写标题与摘要，示意不保证实际展示。
3. 如需AI，展开帮助项，最多选5份本人报告，输入希望改善的方向，再明确点击**用我的AI建议**。只发送所选内容的有限文字及每份最多20条匹配记录，不发送整站、完整报告或密钥；没有匹配数据时不编造统计。
4. 查看变化与依据；可用独立详情网址时，还能查看冻结的实际页面前后版本。没有独立路由时只提供字段示意，并说明原因。
5. 满意后**确认应用到草稿**。不会自动发布，也不改正文、图片、网址、收录开关或动态数据。
6. 在**优化记录**中查看本人历史、撤销或移除。应用后7天内可以安全撤销；若搜索字段已有后续人工修改，会先阻止覆盖。其他正文或其他内容的正常修改不会被这条撤销回退。

修改后输入变化，需要重新准备预览再采用。409冲突或失败时输入和原方案仍保留，**读取最新工作区**只读取服务器状态，不自动重发AI或收费查询。

保留输入只保存查询条件、标题/介绍、指令和报告ID，不把报告正文、模型完整产物、密钥或令牌存入浏览器恢复。恢复只回到输入状态，不自动执行查询、生成、采用或发布。

## 模拟环境与范围

测试环境会醒目标记**模拟数据环境**，报告和建议也带模拟标识；不能把这类结果当作真实Google搜索表现、真实关键词规模或真实模型质量。本阶段不保证排名、收录、点击率增长或询盘增长。接口接线、权限和流程验收与真实账户授权、供应商数据质量是不同的验证范围。
