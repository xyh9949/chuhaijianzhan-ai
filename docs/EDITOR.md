# 响应式编辑器 · 0.3

沿用已有后台、登录、保存和发布流程。本阶段解决页面布局、组件样式和手机端独立调整，不需要新账号或数据迁移。

## 开始设计

1. 在页面管理创建空白页或打开已有页面，进入编辑器。
2. 从左侧拖入元素；也可以点击“添加元素”。选中容器时添加到容器内，未选容器时添加到页面根层。
3. “快速布局”提供两列、三列及侧栏结构，全部由普通容器组成，可继续嵌套、移动和删除。
4. 点击元素或在图层中选择。右侧“内容”修改文案、链接、图片和产品绑定；“样式”修改布局与外观。
5. 保存成功后预览，再到发布管理选择本次改动。保存草稿不会改变已发布网站。

从编辑器打开预览会沿用当前设备宽度。预览同步区块时会打开实际引用它的草稿页面；有多个页面可切换查看，没有可用引用时会标明「区块独立预览」，不跳到首页。「返回编辑器」会回到原页面、模板或区块；预览里的「返回管理后台」会退出预览，在当前标签页打开工作台。

浏览器刷新、前进与后退会恢复该历史位置的编辑对象。草稿未被其他窗口修改时，在同一标签从预览回到原画布可继续撤销或重做。交互模式的同页锚点留在画布，跨页站内链接会另开草稿预览。只读成员可以从网站页面列表预览指定页面或已有的详情样本。

## 三端调整

- 桌面为基础，平板在画布宽度不超过 1024 px 时覆盖，手机在不超过 700 px 时继续覆盖。
- 顶部设备切换与样式面板同步。画布可输入 320–1920 px 宽度，显示缩放比例；缩放只帮助放入工作区，不会改变断点宽度。
- 只需要修改当前设备不同的属性。字段右侧显示“组件默认”“继承桌面”“继承平板”或“独立覆盖”。
- 单项重置删除该项覆盖；“重置手机全部设置”等按钮只清除当前设备设置。修改内容、素材或图层结构在三端共用。
- 隐藏元素不会被删除，仍可从图层选择并恢复显示。

## 布局和样式

容器支持网格、弹性横排/纵排、反序、换行、间距和对齐。子元素可以设置跨列、跨行及排列顺序；网格跨列数应小于等于父容器列数，手机改成单列时通常应把子元素跨列重置为 1。

可设置宽度、最大宽度、高度、最小/最大高度，支持合法的 px、百分比及自动值；四边内外边距独立调整。字体支持风格、字号、字重、行高、字距、颜色、对齐。外观支持背景颜色/图片/焦点、边框、圆角、阴影和透明度；图片可独立裁切与定位。

产品集合和详情是数据绑定区块，字体设置统一作用于区块文字。需要更细的文字层级时，使用独立标题、正文与容器组合。产品详情的主图高度单独提供三端设置。

“复制样式 / 粘贴样式”复制三个设备的自定义样式，不改文案、链接和图片元素的素材（背景图属于样式，会一并复制）；会覆盖目标的自定义样式，可撤销。移动到容器、复制、删除、快速布局和样式设置均进入撤销/重做历史。

## 兼容和边界

已有页面不批量重写；未设置新样式时沿用旧渲染默认值。样式跟随页面进入发布快照，历史版本也保留自己的样式和背景素材。

本版使用可嵌套的网格/弹性布局，未提供任意 CSS/JavaScript 注入、绝对坐标自由画布、全站同步区块、自定义组件代码和自定义断点数量。客户可以从空白页组合设计，现有全站页眉/页脚仍沿用原有组件；需要自建时可在页面内容设置中隐藏默认页眉页脚并用普通元素设计。

升级前备份数据库和媒体。依赖版本沿用锁文件，未修改 Puck 或 Ant Design 包源码；关键回归：旧页面外观、嵌套拖放、三端继承、隐藏恢复、保存重载、私有预览、部分发布和历史恢复。旧版本应用不能识别新样式，应用代码回退请同时使用升级前的数据副本。
