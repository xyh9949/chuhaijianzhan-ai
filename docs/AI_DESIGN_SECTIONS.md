# 挑选页面里满意的AI区块

适用0.31.1（区块挑选自0.29提供），入口：**全站设计 → AI设计整个网站 → 逐页看效果与继续调整 → 只采用部分修改**。0.30扩展[新增、删除与重排的关联组](AI_STRUCTURAL_SECTIONS.md)，0.31可进一步[挑选稳定区块内部](AI_DESIGN_DETAILS.md)。

## 使用方法

1. 生成或打开尚未采用的整站方案，查看修改前后真实页面。
2. 展开“只采用部分修改”。可继续按整页、页眉页脚或全站风格选择。
3. 对可独立拆分的页面，展开页面内区块选择。例如只保留新首屏、保留原产品区，或只采用动态产品区的新卡片。
4. 点击“预览选中修改”。系统生成新的组合方案，原方案、草稿和公开网站保持；挑选已有方案不会调用模型。
5. 核对新的真实预览，再“确认应用到网站草稿”。采用后仍能使用原生拖拽编辑器，公开网站需原发布流程更新。七天内无冲突时可撤销。

改勾选后必须重新预览，不能直接采用旧效果。未提交的勾选、原要求和追问沿用本地恢复保护；0.31.1区块选满仍保留区块单位，不自动扩大为整页，内部项目全选同样保留细分单位。只有明确点“整页采用”或“选择全部修改”才使用整页范围。

## 区块的边界

区块是页面顶层组件的完整子树。例如首屏容器内的标题、图片、按钮作为一组；标签页、折叠面板、轮播内的内容也随其完整根区块处理。不是将历次调整说明当作可单独重放的操作，也不是任意拆开容器里的一个属性。

0.30支持顶层增删、重排、跨根内容迁移的依赖分组；不能拆成独立修改时会一起采用，独立文案仍可选。页面共同设置变化、旧独立分区或源布局超预算时显示原因并保留整页选择。单个方案最多提供200个区块明细；每次最多提交103个范围，明确采用整页时该页为一个范围，不会因选满区块而自动扩范围或静默丢弃选择。锁定内容、位置和祖先样式重新核对；混合组合超预算会拒绝。

所需新动态卡片、同步区块、菜单和图片按实际选中树核对。没有选到的区块所用素材更新不会扩大冲突；选中区块引用的原卡片、菜单或素材失效时拒绝生成组合，不交付缺失依赖。

## 保留手工编辑与撤销

组合预览以当前工作区为新基线。未选区块的文字、样式及锁定状态保留。选中区块已有手改、页面结构改变、资源ID被占用或版本不符时，拒绝覆盖。组合建立后再修改该页面，需要重新核对；当前采用与撤销仍保护完整受影响页面，不会覆盖预览后的手工编辑。

页面内挑选只限制本次采用内容。后续继续用AI调整该页面时仍以页面为任务范围；如需保护某区块，应在编辑器明确锁定，不能把未勾选误当作永久锁定。

## 外部AI及升级

MCP继续使用`site_design_status`和`site_design_select`。原`selectionUnits`保持整页/全站区域，新`sectionUnits`只提供服务器计算的区块ID、父页面、根节点ID和说明。客户端只回传单位ID，不能提交自造节点树；整页与本页区块不能重复选择。原read/propose、页面授权、同连接来源和幂等仍生效，不增加直接保存或发布权限。

读取旧候选时，系统根据冻结的内容树计算区块。派生的新候选仍保存为原生整页 Changes。新版或回退后的实例应验证候选的可读性、采用范围和撤销。[结构组指南](AI_STRUCTURAL_SECTIONS.md) · [升级和回退](../DEPLOYMENT.md#升级和回退)

部分采用、候选执行差异、依赖闭包或撤销保护发生变更时，在隔离实例重新验证。
