# 产品图文长详情

产品编辑页新增 **产品图文详情**，用于用途、卖点、选型说明、包装等长内容。它与原来的产品介绍分开，使用原生图文编辑器，保存后仍能继续修改文字、排版和图片。

## 手工编辑

在 **产品管理 → 新建产品 / 编辑产品 → 产品图文详情** 输入正文。工具栏支持二、三级标题、加粗、斜体、下划线、列表、引用、对齐和链接；图片可直接上传，也可从素材库选择，并可调整宽度、对齐、描述和说明。正文内图片沿用素材引用保护，仍在使用时不能从素材中心直接删除。

产品详情与封面、相册、型号、分类、参数分别维护。保存产品更新工作区；公开网站通过原发布流程更新。富文本不会作为任意HTML或脚本执行。

## 使用AI写长详情

AI继续由管理员在 **站点设置 → AI服务** 自行配置，没有内置账号或额度。新建产品尚未保存时也能准备文案。

1. 在产品图文详情卡片点击 **AI写图文详情**。
2. 核对本次文字依据，按需补充要求、选入已有参数和人工确认的企业资料，再明确生成。一次生成不会保存产品或发布网站。
3. 比较原文与建议，可展开 **查看原文与建议排版** 核对实际标题、列表、图片和链接。
4. 点击 **填入编辑区**，继续使用原图文编辑器修改，再点击 **保存产品**。

长详情使用原生文档结构。模型可调整文字与章节，但必须完整保留已有图片节点和链接标记，不得新增、删除或重复这些引用。新插图和新链接在原编辑器中手工添加；不接收模型HTML。缺少的参数、认证、产能、价格、交期或案例应列为待补，由企业核实。

AI长详情单次上限为30000个正文字符，编辑器原生格式上限沿用60000字符；超限会明确拒绝，不截断原文或自动分批调用。生成长详情会发送本次完整的原生详情文档，其中包含其已有图片地址及链接，供模型精确保留；这不是发送图片文件或整套素材库。只使用明确选择的资料，密钥仅用于连接鉴权。

## 撤回、保存与撤销

- **撤回AI填入** 恢复当前编辑区填入前的内容，保留当时尚未保存的人工输入。同一字段已有后续手工修改时，不强行覆盖。
- 保存后可从AI窗口的 **查看建议与修改** 找到记录并选择 **撤销这次修改**。撤销仅恢复本次相关字段，保留其他参数和产品的后续修改；详情本身已有后改时会拒绝旧撤销。
- 产品原本没有长详情时，撤销会恢复为没有该字段，并清空编辑区；不会留下旧AI内容待下次保存时带回。
- 建议有效40分钟，已保存撤销回执保留7天。保存请求未收到明确确认时，使用原来的 **核对保存结果**，不会重新生成或自动重送保存。

任何保存和撤销都不直接改变公开版本，仍需通过发布管理更新网站。AI结果、人工修改与事实核对遵循原写作流程。

## 页面展示与设计

默认 **产品详情（ProductDetail）** 组件会在基础介绍和参数后显示图文详情，保留该组件的既有模板会自动显示正文。完全自定义且没有该组件的模板不会被自动改写，需要手工配置下述绑定；没有长详情的旧产品沿原样展示。

需要自定义位置时，在产品详情模板中添加原生 **文字（Text）** 组件，将内容绑定到 **产品 → 产品图文详情**（字段键 `builtin:detailContent`）。文字组件会按原生富文本渲染标题、列表、图和链接；只接受纯文字的其他组件取得正文的文字投影。可在页面编辑器拖拽该组件、调整布局与手机样式，正文内部继续由产品图文编辑器维护。

默认产品详情已经显示长详情，在同一模板额外绑定一次会重复展示；按实际设计选择默认整段展示或自定义组件位置。图文正文不会被自动拆成多个独立页面区块。

## 数据与旧版本兼容

新字段为可选的 `Product.detailContent?: RichNode`，未填写时保持缺省，不把旧产品补成空文档。原 `description` 仍是产品短介绍，编辑及AI写作保持1500字符限制，不因新增长详情扩容或被正文替换。

站点快照和渲染协议升至21，数据库协议为18；历史可读下限仍为1。旧快照20保持可读，长详情不需要修改旧产品表的数据结构。发布、真实预览、SEO可见正文和整站分发使用同一原生文档；分发时图片与站内链接沿原规则重映射，源站内容不被改写。

此版本的完整实例备份仍包含私有AI记录；网站内容包不包含连接密钥与私有写作候选。版本更新、恢复与回滚继续遵循原备份/协议检查，不能让较旧程序忽略不认识的原生内容后覆盖新数据。
