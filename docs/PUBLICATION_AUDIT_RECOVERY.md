# 发布诊断、审计与输入恢复

发布协议12，兼容读取1–11。检查按最终候选版本展示页面、产品、模型、记录、区块及全站定义的增删改。未选择内容沿用原公开版本，尚有草稿差异单独计数。依赖建议需明确勾选，之后重新检查。直接影响与保守影响分别标注；列表数量按默认查询估算，不含访客筛选参数。

确认发布绑定预检revision、公开指针和选择范围，任一变化都使检查失效。错误提供修复入口；标题不唯一时进入管理屏而非误开某页。恢复到草稿也需预检范围及依赖，检查不写数据；公开切换与草稿恢复相互独立。

## 审计

发布管理中展开操作审计，管理员可按动作及游标查询。记录草稿/模型/代码修改、导入、发布、切换、恢复、成员与权限及密码重置。CMS成功事件与修改同事务，失败仅记状态码；异步认证记录关联的意图及结果，只有意图不等于成功。升级前不补造历史。

cms_audit为独立追加运行表，网站回退不覆盖。元数据白名单排除密码、代码正文、询盘答案、备注及原始错误；对象ID最多200项并保留总数。完整实例备份应私密保存。

## 输入恢复

表单定义、询盘备注、文件映射、模板保存/复制和整站选项有离开保护。可继续编辑、放弃或保留后离开；有保存能力的表单另有保存并继续。401先保留当前账号输入，重登后只恢复编辑，绝不自动保存、导入或发布。根恢复面板可返回入口、下载副本或移除副本。

缓存按账号隔离、24小时失效、sessionStorage投影最多3MiB；存储不可用时提示仅窗口内存。整站包原文件只留内存，刷新后重选；套件可明确重新载入并保留选项。恢复后代码选择关闭，所有导入和发布需重新检查。允许必填尚未填完，不绕过服务端校验。

备注冲突保留本地文字并展示服务器版本，核对后可明确继续编辑本地内容再保存。重新读取工作区仅在主保存队列已完成时刷新；队列失败先沿用顶部导出/显式重载，避免丢画布。浏览器恢复不是服务器备份，不能保证清理存储后的永久保存。

## 升级

新增审计表与只读接口，无破坏性迁移，协议仍12。升级回归角色撤销、发布/恢复冲突、运行记录独立、401与离开恢复。应用回退须配套匹配版本完整实例备份。
