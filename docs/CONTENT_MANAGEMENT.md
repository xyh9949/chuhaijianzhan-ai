# 按栏目维护内容与产品参数

按栏目维护案例、新闻、团队和其他内容，产品参数在产品管理中配置。

## 平时怎么用

“内容管理”按文章管理的方式使用，案例、新闻、团队各有栏目入口。桌面在左侧选栏目，手机用顶部栏目下拉。选中栏目后点击“新建案例 / 新建新闻 / 新建成员”，进入完整写作页；要修改已有内容，直接点击标题或编辑。主区域编辑封面、标题、摘要和正文，专用资料与网站状态放在右侧；点击“保存草稿”后留在当前文章，继续编辑。

首次启用内置栏目，会建立一组现成填写项目和可编辑详情页草稿；不会生成任何案例、新闻、成员记录，也不会自动发布。仅打开栏目列表不写入数据库。栏目启用后，即使取消新内容编辑，栏目和详情页草稿仍保留。已有同类栏目直接显示原名称，不改写或合并旧资料。

- 案例：名称、图片、国家/地区、简介、项目详情。
- 新闻：标题、图片、摘要、正文、作者、内容日期。
- 团队：成员姓名、照片、职位、成员介绍。

封面与正文图片都可直接上传或按缩略图从素材库选择，上传归入“内容图片”。正文图片可以添加替代文字、下方说明，调整宽度与对齐。上传过程中不能保存或无提示离开，成功响应不重置已填正文。封面和正文插图分别维护。

列表显示封面、标题与摘要；草稿、已发布、有修改待发布及标题搜索用于日常查找。语言、分类标签与批量导入收在“筛选与批量导入”；导入先选具体栏目。新建内容时若尚未选栏目，会先让你选择，不再默默选第一栏。

“预览”会在需要时先保存当前草稿，再打开实际详情预览；只读查看不会写入。管理员可以在文章右侧点击“检查并发布内容”或“检查并更新网站”，进入原发布检查与确认流程，也可以到发布管理集中更新。预览和保存都不会直接发布。内置栏目的详情页随对应内容发布后拥有独立网址；网站首页或列表的布局仍由页面编辑器设计。

## 需要调整栏目时

选中具体栏目，打开“栏目设置”：修改填写项目、设计/设置详情页、管理分类标签。填写项目不再与日常内容并列为一级标签。所有内容的公共分类可在“全部内容”的“分类与标签”中查看；产品分类不出现在这里。

“添加栏目”保留案例、新闻、团队之外的工厂能力、选型比较、检测认证、采购指南和自定义栏目。自定义栏目可自由定义填写项目，再通过“栏目设置”设置详情页。已有字段标识、类型、关联与删除引用保护沿用原规则；修改显示名称不会迁移旧资料。

## 产品参数在哪里

进入“产品管理 → 产品参数”。在“产品参数”页新建参数组、设置需要填写的项目，例如长度、宽度和表面处理。之后在产品编辑里的“使用哪组产品参数”选择该组，填写具体数值。基础产品和多图不依赖参数组。

产品参数设置中只显示产品参数组；内容管理只显示内容栏目。参数组的旧ID、字段ID及产品值原样保留，改名仍保持关联，数字0与“否”不丢失。“分类与标签”页只管理产品分类。

## 权限与维护

管理员设置栏目与参数；编辑者填写内容、查看填写项目；只读成员可切换栏目、搜索、查看资料，不能保存。局部Ant ConfigProvider只解除浏览控件的全局禁用，字段只读、写按钮权限和服务端权限验证均保留。编辑者改栏目结构、只读成员写入，实际HTTP均403；编辑者填写内容HTTP200。

0.10复用原工作区队列与草稿发布API，通过可选排版正文数据保存富文本；新发布协议19读取1–19，没有SQL迁移或批量数据重写。旧多行文本字段和ID保持，打开旧文章不会自动迁移、保存或标成已修改。数据兼容与回退见[写作说明](ARTICLE_WRITING.md#维护与数据兼容)。内容与产品参数的会话恢复副本分别保存，兼容旧单键缓存；一个入口保存或明确放弃，只清理自己的恢复副本。上传活动进入保存/离开/卸载保护。界面沿用当前Ant Design商务风，没有引入组件或编辑器依赖。
