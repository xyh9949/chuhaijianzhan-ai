# AI整站设计

0.22新增外部AI与MCP/Skill入口，见[外部连接说明](EXTERNAL_AI.md)。下文为0.21整站设计能力及原生编辑/撤销规则，继续适用。

应用0.21.0。入口：**网站页面**或**全站设计 → AI设计整个网站**。仅管理员可用，继续使用**站点设置 → AI服务**中用户自己配置的模型。

## 用一句话调整整个网站

例如：“我们面向海外工程采购，整个网站要更专业。页眉简洁、产品更好找，页脚联系方式更清楚，各页字体和留白统一，手机也方便浏览。”

默认包含全部页面、页眉、页脚、导航与全站风格。无需填写设计参数。点击生成后，先查看AI对需求的理解、设计决定、保留内容和假设，以及实际影响页面；生成和预览不采用修改。

在同一候选中逐页切换电脑、平板、手机预览。满意的地方可以保留，继续说“导航再简洁一点，手机页脚更紧凑”。初次生成后最多继续六次，每次由用户主动调用一次模型，不自动付费重试。

确认后点击**确认应用到网站草稿**。页眉页脚是原生可拖拽区块，导航使用真实页面目标；可以从结果直接进入原编辑器。网站尚未发布，公开站点仍走原发布流程。

## 同步与独立设计

- 跟随全站的页眉、页脚会同步使用新设计，原共享区块和菜单保留为原资产。
- 原本隐藏头尾、空白画布或独立布局默认保持。明确说“让独立页面也使用新页眉，页脚仍隐藏”，AI可以只调整指定一侧，不连带显示另一侧。
- 全站字体、颜色、圆角与默认排版可统一；已有局部样式、样式库引用和条件详情模板布局不会被悄悄清除。独立详情模板仍可能继承新的全站默认样式，匹配记录继续使用模板自己的布局，应结合真实详情样本核对。需要具体页面进一步统一时，可继续提出页面编排要求。
- 新物化的默认页眉按每种语言保留原有效导航；品牌使用独立的首页链接，不会因整理主导航而改跳其它页面。各语言有独立首页时，品牌返回对应语言首页；缺少该语言首页时会提示，并保留当前页顶端链接，不擅自跳回默认语言。默认页脚原本没有导航时，不会仅因重新设计页脚就增加导航。
- 品牌链接在手机上也直接显示公司名；普通导航默认折叠为菜单。原生导航的“手机显示方式”可随时改为始终显示链接，仍能拖拽和维护真实菜单。
- 影响列表与真实预览用于核对实际结果；自定义CSS保留，预览不运行客户JavaScript。缺少真实详情样本的页面会注明不能预览，可回原编辑器检查。

可选范围中选择部分页面时，页眉页脚、导航及全局风格操作自动关闭，只允许修改所选页面，避免影响未选页面。已锁定内容不能通过全局继承绕过；发生冲突时会明确拒绝，并保留指令。

目前采用保守的全站锁定保护：任一页面、共享区块或页面模板包含锁定节点时，全站主题、页眉页脚及导航操作均会拒绝；仍可调整所选页面内未锁定的原生节点。明确要求改变某页的头尾显示方式时，该页也不能含锁定节点。

“保留页面和头尾文案”保护页面与原生头尾文案，导航仍可按要求重新整理。新导航项来自真实静态页面；已有外链或分组可保留，新任意外部网址不在本批AI操作范围。

内置或隐藏头尾不能在“保留页面和头尾文案”开启时替换成新的区块设计。内置区域含固定标语、按钮或动态版权内容，新的资料种子无法承诺逐字保留。此时可调整全站风格、页面或不重建区域的导航；需要重新设计头尾时，先允许头尾文案变化。已有原生自定义头尾仍可保留文案并重新排版。

高级边界：默认内置页眉没有独立菜单，或多语言品牌需要新的独立菜单表示时，把它改为原生可编辑区块需要同时允许导航；未允许时会提示，不暗中替换菜单。单语言且已有有效菜单的默认页眉可保留原导航引用；已有自定义头尾可单独设计并保留其导航引用。

## 预览和继续调整

候选保存最初网站与累计设计后的版本，预览全部来自同一冻结候选，不读取实时草稿补值。页面选择器可以核对改变与未改变的页面，已影响页面优先显示。

对比窗口中已知页面导航会同步切换修改前后。非代表详情、筛选分页等可在**打开完整预览**中浏览，避免对比标签与实际页面不一致。过期、删除或权限失效不会退回当前草稿冒充原候选。

基础排版检查包括当前视口的溢出、图片、过小文字/手机操作区域和一级标题数量。继续调整可携带本候选已检查的最多五个目标页面、每页三端的受限计数与节点标识，不包含正文、URL或凭据。它是几何建议，不是截图视觉审查或设计满意度评分。

“设计调整记录”包含连续修改过程；最终效果以当前前后预览与实际影响页面为准。长正文在整站上下文中可能只提供明确标记的摘录，AI不能借摘录重写未读全文；详细正文仍可使用原局部编辑入口。

当前一次可选择1–100个页面，压缩后的整站结构上下文上限为12万字符，私有候选资料上限10MB；输入超限会在调用模型前提示，生成后的候选也会再次检查容量。页面很多或结构复杂时，可分批处理正文，但全站区域和主题仍要求选择全部页面，不能用分批选择绕过影响范围保护。

## 确认和撤销

确认在同一事务中写入涉及的页面、全局风格字段、布局槽位及新独立区块/菜单，保留其他产品、文章、设置、询盘和公开版本。相同确认重试不会重复生成资源。

采用后七天内可查看历史并**撤销本次整站设计**。只反转本次涉及的字段与页面，不用旧整站快照覆盖最新业务资料。目标页面/区块/菜单已被修改、生成资源出现新外部引用、全局变化触及新锁定内容时，会先拒绝覆盖。全局默认的撤销仍影响后来继承这些默认值的新页面，但不删除新页面正文。

未采用候选可访问40分钟，已采用记录提供七天撤销入口；到期记录在后续生成新方案时清理。移除已采用记录不会删除网站内容，但会失去该记录的撤销入口。过期或删除后，未提交追问可以放回输入框，不自动重新调用模型。

## 升级和维护

升级编辑器、导航或发布协议时，在隔离副本验证旧快照、手机导航、页眉页脚引用和现有候选。

回退应用程序前保留当前客户数据库、媒体、密钥和配置，先验证回退版本与最新资料的兼容性。撤销已采用的方案使用该候选的审核入口。[升级和回退](../DEPLOYMENT.md#升级和回退)

整站设计也可通过[外部 AI](EXTERNAL_AI.md)接入。计划对外发布时，应使用真实资料审阅设计、内容和 SEO 建议。
