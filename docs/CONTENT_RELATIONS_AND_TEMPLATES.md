# 内容关联与条件详情模板

## 关系字段

管理员在内容模型中新增“关联内容”，目标为全部产品、某个产品模型或某个独立内容模型，设置单选/多选。目标和单多选保存后不可原地更改；需要另建字段并显式迁移。关系仅存稳定ID，多选最多50条并保留选择顺序；全站最多10000条引用边。

产品和内容记录使用相同的Ant选择器，多选下方可上下调整顺序。未发布目标允许选进草稿。公开发布的最终候选必须明确包含每个被引用目标及其模型，不自动携带草稿。强引用目标删除前先解除关系，历史版本不修改。双向业务关联合法，但展示只展开一跳，不支持深层字段表达式或递归查询。

绑定面板可选“关联标题”，多条以逗号连接；单选另可选“关联详情链接”。链接需要实际默认详情页，不能用资源模板代替公开路由。产品详情规格区直接展示关联标题，存在实际详情入口时附链接。目标字段内容均作为文本输出。

CSV/JSON导入关系值使用目标稳定ID；多选CSV单元格填写JSON数组，例如 `["case-a","case-b"]`。只可关联当前实例已有记录；整站包迁移会按种类和字段所属模型重命名ID，不能直接把另一实例的CSV关系ID当作本实例ID。

## 当前记录的关联循环

在“自由卡片循环列表”中把“记录范围”改为某模型的关系字段。编辑器自动确定输出来源和目标模型；切换目标种类或模型会解除旧卡片，避免沿用不兼容绑定。普通页面先设置默认记录，详情页使用URL对应记录。区块继承调用页面，卡片使用当前循环项；编辑样本不会覆盖真实详情。

循环默认保留关系选择顺序，开启查询后仍默认“关联选择顺序”；只有明确选择排序字段才覆盖该顺序。搜索、分类、筛选与分页均先限制在关联集合。空关系使用组件的空状态文案，不回退到全站集合。分页越界返回404，检查与SSR使用相同集合。发布诊断中关联列表依赖当前记录，数量显示“无法估算”，从具体记录地址预览核对。

自由卡片仍复用同步区块编辑器，不开放卡片里的二次循环。引用深度8层、展开10000节点和每页50项预算继续生效。

## 条件详情布局

默认详情页面负责唯一URL、SEO、页面代码和兜底。管理员先从实际产品/内容详情页保存资源模板，再在“页面模板资源库 → 详情条件”配置：

1. 启用规则，设置0–1000优先级，数字越大越先匹配。
2. 产品可限定模型；独立内容由资源用途固定模型。
3. 可限定具体记录与任一分类。不同条件同时满足；留空不限制。
4. 选择一条记录查看草稿命中说明，再使用该记录的 `/preview/...` 地址核对实际布局。

同优先级只接受能证明互斥的模型或具体记录集合。即使目前没有记录同时命中，潜在重叠也被拒绝，避免新增记录后随机选布局。启用规则必须有默认详情页兜底；规则引用的记录/分类必须进入最终版本。没有匹配使用默认页面，切换布局不改记录URL。

规则作为 `PageTemplate.detailRule` 随**页面模板资源库及详情条件规则**整套显式发布/恢复，不另设重复全局配置。勾选此范围前核对所有模板草稿更改。未选规则沿用线上资源，不悄悄上线。更新带规则资源的设计只允许同用途/同模型来源，保留规则。

条件资产只提供布局。它保存的CSS/JS不会因为命中规则自动启用，代码继续使用默认详情页的明确设置。需要条件专用样式请使用节点三端样式或管理员已核对的全站选择器；不自动执行资产程序。模板内同步区块与媒体仍进入依赖检查、发布和历史恢复。

规则弹层有离开确认、401本地恢复和409保留输入；恢复只回到编辑状态，不自动保存或发布。

## 兼容、权限与交付

协议集中在 `src/lib/protocol.json`：S11为13，继续读取真实1–12旧结构。SQL迁移仍1–3，没有修改已登记迁移或重写旧客户数据。旧版无关系/规则时继续使用原默认详情与普通集合。回退旧应用必须配套旧数据，不能把协议13库交给只支持12的旧程序继续写入。

模型与条件规则管理仅管理员；编辑员可填写已有关系值、修改页面/卡片；只读成员不可写。发布、回退、恢复沿用现有权限。整站包导入映射关系定义、值、派生字段、关联循环、条件记录/分类与模型；仍默认关闭JS，不含账号/询盘/密钥。
