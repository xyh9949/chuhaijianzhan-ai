# Security policy

To send a private report, use **Security and quality → Report a vulnerability** in the GitHub repository when private vulnerability reporting is enabled. If the button is unavailable, open an issue asking for a private contact and keep technical details out of the public issue. [GitHub reporting guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)

Include the affected version or commit, deployment type, relevant settings, and a minimal reproduction using fictitious data. Keep tokens, passwords, cookies, customer records, and complete instance backups out of reports. Coordinate public disclosure with the maintainers so they have time to investigate and prepare a fix.

通过仓库的私密漏洞报告入口提交安全问题。入口未开启时，可在公开 Issue 中询问私密联系方式，漏洞细节请通过私密渠道发送。
